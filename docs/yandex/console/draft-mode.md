# Режим черновика







{% note alert %}

Требуются [регистрация](https://yandex.ru/dev/games/doc/console/manage-account) на платформе Яндекс Игры и [черновик игры](https://yandex.ru/dev/games/doc/console/add-new-game#create-draft).

{% endnote %}

Этот способ тестирования подходит на этапе финальной проверки игры перед отправкой на модерацию. В этом режиме игра взаимодействует с реальной платформой Яндекс Игры.

Особенности:

- Игра открывается по реальному адресу на [yandex.ru/games](https://yandex.ru/games){.external}.
- Чтобы отправлять запросы на внешние хосты, их нужно [добавить](https://yandex.ru/dev/games/doc/console/add-new-game.md#check-host) в правила для CSP.
- Показывается настоящая реклама.
- Игрок авторизуется через Яндекс Паспорт.
- Данные игрока и лидербордов сохраняются на сервере.
- Каталог товаров загружается с сервера, покупки обрабатываются на сервере.
- Для отладки можно использовать [debug-панель](https://yandex.ru/dev/games/doc/console/debug-panel.md) через параметр адресной строки `&debug-mode=16`.

## Открыть игру в режиме черновика {#open-draft-mode}

1. Зайдите в [Консоль](https://games.yandex.ru/console){.external} с аккаунтом разработчика.

1. В левом верхнем углу Консоли нажмите [Игры](https://games.yandex.ru/console/applications){.external}.
1. Найдите в списке игру, которую планируете протестировать, и нажмите на нее.
1. Откройте черновик:
    - Если вы редактируете игру впервые, нажмите **Создать черновик**.
    - Если у вас есть черновик, он откроется автоматически.
    - Если у игры есть несколько неопубликованных версий, нажмите на название одной из них.
1. Проверьте, что загружен актуальный [архив](https://yandex.ru/dev/games/doc/console/add-new-game.md#field-archive). Если нет:
    1. Выберите новый файл.
    1. Нажмите **Сохранить**.
    1. Обновите вкладку **Черновик**.
1. В поле **Архив** перейдите по одной из ссылок:
    - **Открыть черновик**, чтобы проверить, как игру будут видеть пользователи.
    - **Открыть черновик с debug-панелью**, чтобы протестировать игру в различных сценариях.
