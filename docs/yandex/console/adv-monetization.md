Вы можете получать доход от размещения рекламных блоков. Как подключить рекламу, зависит от схемы сотрудничества:

- Россия, юридическое лицо или ИП — по [единой лицензионной схеме](https://yandex.ru/dev/games/doc/payments.md) реклама включается автоматически вместе с договором, регистрироваться в РСЯ не нужно. Но чтобы блоки заработали, нужно [добавить код SDK](https://yandex.ru/dev/games/doc/sdk/sdk-adv.md) в игру и при желании [настроить стики-баннеры](https://yandex.ru/dev/games/doc/sdk/sdk-adv.md#sticky-banner).
- Остальные случаи — подключите [внутреннюю](https://yandex.ru/dev/games/doc/ru/#internal-monetization) и [внешнюю](https://yandex.ru/dev/games/doc/ru/#external-monetization) монетизацию через РСЯ.



## Рекламные блоки {#ads}

{% note info %}

Показ рекламы возможен только при игре в онлайн-режиме (с доступом в интернет). Во время игры без интернета рекламные блоки не отображаются, а учет показов и переходов не ведется.

{% endnote %}

### Полноэкранные блоки {#interstitial}

Полноэкранные блоки — это блоки с рекламой, которые полностью закрывают фон приложения и показываются в определенные моменты (например, при переходе на следующий уровень игры).

Он располагается в центре и может занимать только часть экрана, но игровое поле полностью перекрывается фоном блока.

Создается автоматически при [подключении монетизации](https://yandex.ru/dev/games/doc/ru/#enable-int-monetization).

### Блоки с вознаграждением {#rewarded}

Блоки с вознаграждением (rewarded video) — блоки с видеорекламой, которые пользователь может просматривать по своему желанию и получать за просмотр награду или внутриигровую валюту.

Создается автоматически при [подключении монетизации](https://yandex.ru/dev/games/doc/ru/#enable-int-monetization).

{% endcut %}

### Стики-баннеры {#sticky}

Стики-баннер — это рекламный баннер, который отображается в игре постоянно. По умолчанию показом управляет платформа Яндекс Игр, но опционально для скрытия и отображения баннера можно использовать API Яндекс Игр.

[Настройка стики-баннера](https://yandex.ru/dev/games/doc/sdk/sdk-adv.md#sticky-banner) производится в Консоли разработчика:

- для мобильных устройств можно указать расположение баннера в портретной и альбомной ориентации;
- для десктопов можно включить показ баннера, он будет располагаться справа.

## Внутренняя монетизация {#internal-monetization}

Внутренняя монетизация работает через [Рекламную сеть Яндекса (РСЯ)](https://yandex.ru/support/partner/ru/){.external} с помощью технологии продажи и покупки рекламных показов в реальном времени — Real Time Bidding (RTB). RTB позволяет максимизировать доход от показа рекламы, так как работает по принципу аукциона и автоматически выбирает наиболее выгодное из предложений рекламодателей.

В рекламных блоках показываются только посещаемые и качественные рекламные ресурсы. В соответствии с [правилами Рекламной сети](https://yandex.ru/legal/partner/){.external} Яндекс не принимает к участию ресурсы с некачественным контентом или созданные специально для заработка на размещении рекламы.

Внутренняя монетизация работает на доменах для РФ и СНГ: yandex.ru, yandex.kz, yandex.uz, yandex.by.

### Подключение {#enable-int-monetization}

{% note info %}

Инструкция ниже — для тех, кто работает через РСЯ. Если у вас [единая лицензионная схема](https://yandex.ru/dev/games/doc/payments.md), реклама уже подключена: осталось [добавить код SDK](https://yandex.ru/dev/games/doc/sdk/sdk-adv.md) и при желании [настроить стики-баннеры](https://yandex.ru/dev/games/doc/sdk/sdk-adv.md#sticky-banner).

{% endnote %}

1. [Добавьте код SDK](https://yandex.ru/dev/games/doc/sdk/sdk-adv.md) в исходные файлы игры.
1. Зайдите в [Консоль](https://games.yandex.ru/console){.external} с аккаунтом разработчика.
1. В левом верхнем углу Консоли нажмите [Игры](https://games.yandex.ru/console/applications){.external}.
1. Найдите в списке ранее загруженную игру и нажмите на нее.
1. [Загрузите архив](https://yandex.ru/dev/games/doc/ru/add-new-game.md), в котором содержатся исходные файлы игры с кодом SDK.

    На каждую добавленную игру, где есть код SDK, автоматически добавится по одному [рекламному блоку](https://yandex.ru/dev/games/doc/ru/#ads). Список всех рекламных блоков будет доступен для просмотра в [партнерском интерфейсе РСЯ](https://partner.yandex.ru/){.external}. Вы также можете включить [стики-баннеры](https://yandex.ru/dev/games/doc/ru/#sticky).

    {% note info %}

    Рекламные блоки будут созданы после публикации игры при условии успешной регистрации в РСЯ.

    {% endnote %}

1. Перейдите на вкладку **Реклама**.
1. Выполните следующие действия:

    {% list tabs %}

    - У меня есть аккаунт РСЯ

      Убедитесь, что ваш аккаунт Рекламной сети Яндекса (РСЯ) имеет такой же логин, как аккаунт в Играх. Это важно для корректного подключения рекламной монетизации.

      Если логины отличаются, создайте новый аккаунт РСЯ с таким же логином, как в Играх, по инструкции **У меня нет аккаунта РСЯ**.

      Проверьте, что в вашем аккаунте РСЯ указаны актуальные контакты и реквизиты. Эти данные используются для выплаты вознаграждений. Подробнее см. раздел [Настройки аккаунта пользователя](https://yandex.ru/support/partner/ru/account-settings){.external} Справки РСЯ.

    - У меня нет аккаунта РСЯ

      1. Нажмите кнопку **Подключить монетизацию**.
      1. Заполните анкету. Указывайте только актуальную информацию, так как эти данные используются для выплаты вознаграждений. Подробную инструкцию см. в разделе [Регистрация](https://yandex.ru/support/partner/ru/joining/application-form#application){.external} Справки РСЯ.

      1. Ознакомьтесь с [Условиями участия в Рекламной сети Яндекса](https://yandex.ru/legal/yan_service_offer/){.external} и подтвердите согласие на обработку и хранение персональных данных.
      1. Нажмите кнопку **Зарегистрироваться**.

         Теперь вы можете загружать новые игры и зарабатывать на платформе.

         По условиям оферты РСЯ, выплата вознаграждения будет возможна после того, как вы внесете реквизиты для выплат в партнерском интерфейсе РСЯ и получите письмо от РСЯ, что ваша оферта акцептована.

    {% endlist %}

1. Проверьте, что игра готова к отправке на модерацию:

   - В черновике игры корректно настроен вызов рекламы, согласно [разделу 4](https://yandex.ru/dev/games/doc/concepts/requirements.md#4) Требований к игре.
   - Стики-баннеры настроены, если это необходимо.

   {% note info %}

   В [режиме черновика](https://yandex.ru/dev/games/doc/console/test-game.md) будут показаны рекламные блоки Яндекса.

   {% endnote %}

1. [Отправьте игру на модерацию](https://yandex.ru/dev/games/doc/ru/add-new-game.md#moderation-game) и дождитесь ее успешного прохождения.

    {% note info %}

    Если игра была на проверке больше 100 дней назад, вы увидите предупреждение, что требования могли измениться. Откажитесь от отправки на модерацию, ознакомьтесь с требованиями и проверьте, соответствует ли им игра. После этого повторно отправьте игру на модерацию.

    {% endnote %}

1. На вкладке **Черновик** нажмите **Опубликовать**. Через пару минут статус изменится на **Опубликовано**, и пользователи смогут найти вашу игру в каталоге [Яндекс Игр](https://yandex.ru/games/){.external}.

### Выплаты {#money-int}

Вознаграждение выплачивается, когда сумма дохода достигнет определенного порога. Размер вознаграждения, порог, способ и сроки выплаты зависят от вашего юридического статуса и страны проживания. Подробную информацию см. в разделе [Как получить вознаграждение](https://yandex.ru/support/partner/ru/payments/){.external} Справки РСЯ.


{% note info %}

Рекламные блоки приносят доход за видимые показы. Показ считается видимым, если не менее 50% площади блока находится в видимой зоне экрана не менее двух секунд. Многоступенчатая технология фильтрации распознает недобросовестные и ошибочные клики по баннерам, и в случае таких кликов доход за показы не начисляется. Подробнее об этом см. в разделе [Защита рекламодателей](https://yandex.ru/support/partner/ru/technologies/antifraud){.external} Справки Рекламной сети Яндекса.

{% endnote %}

### Статистика {#statistic-int}

{% note info %}

Статистика доступна только после публикации игры и создания реальных рекламных блоков.

{% endnote %}

Учет покупок, показов и переходов по рекламным блокам начинается сразу после их добавления в игру. Расчеты производятся на основании данных Системы учета статистики Яндекса.

Если вы работаете не по [единой лицензионной схеме](https://yandex.ru/dev/games/doc/payments.md), вы можете посмотреть статистику по рекламным блокам в [партнерском интерфейсе РСЯ](https://partner.yandex.ru/){.external}:

1. Перейдите на вкладку **Статистика**.
2. Выберите фильтры **Сайт / приложение** и **Название блока** (например, `fullscreen` или `rewarded`). Тип блока указан в названии блока.

   {% note info %}

   Не выбирайте фильтр **Тип блока**, поскольку все блоки в Играх имеют тип «Баннер».

   {% endnote %}

3. Постройте отчет.

Канал **Реклама** объединяет доходы от всех рекламных сетей, с которыми сотрудничает платформа Яндекс Игры. Посмотреть доход можно в [Консоли разработчика](https://games.yandex.ru/console){.external} на вкладке **Метрики** → **Метрики монетизации** → **Доход**.

## Внешняя монетизация {#external-monetization}

Внешняя монетизация подключается в интерфейсе РСЯ, но работает через другие рекламные сети, например Google, MyTarget.

Она работает на домене yandex.com для всех стран.

### Подключение {#enable-ext-monetization}

{% note info %}

Инструкция ниже — для тех, кто работает через РСЯ. Если у вас [единая лицензионная схема](https://yandex.ru/dev/games/doc/payments.md), внешняя монетизация уже подключена автоматически.

{% endnote %}

1. [Подключите монетизацию](https://yandex.ru/dev/games/doc/ru/#enable-int-monetization).

1. Зайдите в [партнерский интерфейс РСЯ](https://partner.yandex.ru/){.external}.
1. В баннере **Подключите внешние рекламные сети** нажмите **Подробнее**.

    {% cut "В интерфейсе РСЯ нет баннера" %}

    Возможные причины:
    - Внешняя монетизация уже подключена.
    - Ваше юридическое лицо — нерезидент РФ. В этом случае подключение внешней монетизации занимает больше времени, и баннер появится через несколько рабочих дней.

    {% endcut %}

1. Нажмите **Подключить**. Внешняя монетизация начнет работать автоматически.

### Выплаты {#money-ext}

В зависимости от валюты договора для выплаты установлен порог:
- 3000 рублей;
- 150 долларов США;
- 100 евро;
- 500 дирхам ОАЭ.

Сама выплата произойдет автоматически на реквизиты партнера, указанные в Партнерском интерфейсе РСЯ, в течение 20 рабочих дней следующего месяца.

### Статистика {#statistics-ext}

{% note info %}

Статистика доступна только после публикации игры и создания реальных рекламных блоков.

{% endnote %}

После подключения внешняя монетизация работает автоматически, а доходы от нее учитываются в канале **Реклама**. Посмотреть доход можно в [Консоли разработчика](https://games.yandex.ru/console){.external} на вкладке **Метрики** → **Метрики монетизации** → **Доход**. Еще сумму вознаграждения можно увидеть в актах и отчетных документах, которые приходят на почту после достижения порога выплат.
