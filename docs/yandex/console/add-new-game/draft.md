# Заполнение черновика







Заполнение вкладки **Черновик** — один из ключевых этапов [загрузки игры](https://yandex.ru/dev/games/doc/add-new-game.md) в каталог Яндекс Игр. Вкладка разделена на два блока:

- [Общее](https://yandex.ru/dev/games/doc/ru/#general): поля с основной информацией об игре, которая не меняется в зависимости от языка.
- [Описание и продвижение](https://yandex.ru/dev/games/doc/ru/#description-and-promotion): тексты, изображения и видео, которые используются для продвижения в каталоге и рекламных сетях.

Рядом с названиями полей, заполнение которых обязательно, расположен значок **<span class="red">*</span>**.

{% note tip %}

Справа от всех полей находятся подсказки. Чтобы увидеть их, наведите курсор на ![SVG](https://yandex.ru/dev/games/_images/icons/question-mark.svg).

{% endnote %}

### Описание и продвижение {#description-and-promotion}

По умолчанию в Консоли заданы основные языки — русский и английский. Вы можете:

- Добавить локализацию на другой язык — нажмите ![SVG](https://yandex.ru/dev/games/_images/icons/add-purchase.svg) и выберите нужный язык из списка.
- Убрать неиспользуемый язык — справа от него нажмите ![SVG](https://yandex.ru/dev/games/_images/icons/delete-button.svg).

Описание нужно заполнить для каждого из выбранных языков. Чтобы переключиться на черновик другого языка, выберите соответствующую вкладку. На каждой вкладке вы можете оценить [заполненность карточки](https://yandex.ru/dev/games/concepts/ranking-and-featuring.md): чем полнее описание, тем лучше продвигается игра.

Чтобы упростить публикацию на других языках, используйте функцию [AI-описания](https://yandex.ru/dev/games/concepts/languages-and-domains.md#ai-descriptions). Добавьте описание на английском языке, и система автоматически создаст переводы на его основе.

{% note info %}

До публикации игры опция **Хочу подключить AI-описания** включена по умолчанию. Она отображается внизу страницы.

{% endnote %}

Вы можете скачать креативы из черновика в исходном качестве. Для этого:
1. Наведите указатель на нужный материал.
2. В правом нижнем углу нажмите ![SVG](https://yandex.ru/dev/games/_images/icons/download.svg) **Скачать изображение** / **Скачать видео**.

## Шаг 1. Технические параметры {#technical}

Загрузите архив с игрой и укажите технические параметры.

### Версия {#version}

Вы можете указать название версии, по умолчанию название первой из них — 0.0.0.1.

### Архив <span class="red">*</span> {#field-archive}

Загрузите ZIP-архив с игрой.

Требования к архиву:

- Содержимое архива до сжатия весит не более 100 МБ ([пункт 1.21](https://yandex.ru/dev/games/concepts/requirements.md#1-21)).
- В корне есть один файл `index.html` ([пункт 1.22](https://yandex.ru/dev/games/concepts/requirements.md#1-22)).
- В названиях файлов и папок нет пробелов и кириллических символов ([пункт 1.22](https://yandex.ru/dev/games/concepts/requirements.md#1-22)).

{% note warning %}

Единовременно может быть прикреплен только один архив. Если загрузить файл заново, он заменит текущий.

{% endnote %}

Мы рекомендуем хранить игры на сервере Яндекса. Если игре нужна сложная серверная архитектура (например, для мультиплеера), вы можете подключить ее через `iframe`. Для этого напишите в [чат поддержки](https://yandex.ru/chat/#/user/774df508-c12d-9d6e-6a27-5e3fc522016a){.external} и укажите: {#iframe}

- название игры;
- аккаунт разработчика;
- ссылку на игру в формате `https`;
- причину, по которой загрузка через архив не подходит.

### Поддерживаемые платформы <span class="red">*</span> {#field-supported-platforms}

Список поддерживаемых платформ, который будет использоваться для автоматической фильтрации игр в каталоге Яндекс Игр. Например, если выбрана только платформа **Мобильные** → **iOS**, то игра не будет показываться у пользователей на платформах Android и десктопе.

Выберите платформы, на которые портирована игра:

- **Десктоп**
- **Мобильные**

  Чтобы выбрать OC, нажмите ![SVG](https://yandex.ru/dev/games/_images/icons/lock-platforms-mobile.svg):

  - **iOS**
  - **Android**

- **ТВ**

### Ориентация <span class="red">*</span> {#field-orientation}

Для мобильной платформы выберите ориентацию, в которой будет работать игра:

- **Портретная** — вертикальное положение экрана.
- **Альбомная** — горизонтальное положение экрана.
- **Любая** — если игра корректно отображается в обеих ориентациях.

Если выбрана опция **Портретная** или **Альбомная**, в неподдерживаемой ориентации пользователь увидит заглушку от SDK с просьбой повернуть экран.



## Шаг 2. Метаданные {#metadata}

Укажите метаданные игры. Они влияют на ее видимость в каталоге.

### Рекомендуемые языки перевода {#field-recommended-lang}

{% note tip %}

Рекомендуем перевести игру на английский и русский языки.

Для прохождения модерации необязательно заполнять черновик на каждом языке, но это влияет на видимость игры в других странах. Добавьте метаданные на английском, чтобы больше пользователей по всему миру увидело игру.

{% endnote %}

### Игра переведена на <span class="red">*</span> {#field-languages}

Чтобы игра успешно открывалась в соответствующей локализации, укажите языки, на которые переведено приложение ([пункт 8.2.3](https://yandex.ru/dev/games/concepts/requirements.md#8-2-3)): выберите из выпадающего списка или начните вводить название. Модерация проверит, поддерживает ли игра все заявленные языки.

#### Автоопределение языка {#add-lang}

Чтобы автоматически определять, на каком языке отображать игру для пользователя, используйте язык портала, указанный в параметре [i18n.lang](https://yandex.ru/dev/games/sdk/sdk-environment.md#structure-i18n) из SDK Яндекс Игр.

Вы можете проверить, правильно ли реализовано автоопределение, с помощью debug-панели. Подробнее см. в [методике проверки](https://yandex.ru/dev/games/requirements/2/14.md) пункта 2.14.

{% note warning %}

Автоопределение языка обязательно ([пункт 2.14](https://yandex.ru/dev/games/concepts/requirements.md#2-14)), но в игре может быть настройка для переключения на другой язык вручную.

{% endnote %}

#### Тестирование игры на разных языках {#testing}

1. Запустите игру с [debug-панелью](https://yandex.ru/dev/games/doc/debug-panel.md#debug-panel-on).
1. Нажмите [кнопку инструментов](https://yandex.ru/dev/games/doc/debug-panel.md#tools-button) **SDK mocks** ⚒️.
1. В выпадающем списке выберите нужный язык. Игра откроется на нем в новой вкладке.

{% note tip %}

Чтобы открыть игру сразу на нужном для тестирования языке, на вкладке **Черновик** в поле **Игра переведена на** нажмите на выбранный язык. Игра откроется на нем в новой вкладке.

{% endnote %}

### Возрастной рейтинг <span class="red">*</span> {#field-age-rating}

Укажите [возрастное ограничение](https://yandex.ru/dev/games/requirements/2/7.md) для вашей игры.

### Категории <span class="red">*</span> {#field-category}

Категории — это жанры, к которым относится игра.

Вы можете выбрать не более двух категорий.

### Теги {#field-tags}

Теги, описывающие особенности вашей игры.

Вы можете добавить до 20 тегов.

### Ключевые слова {#field-keywords}

Список ключевых слов, по которым пользователи смогут найти игру через Поиск Яндекса.

Слова указываются только в нижнем регистре и разделяются между собой запятыми.

Максимальное количество символов в поле — 100.



## Шаг 3. Дополнительные параметры {#additional}

Укажите дополнительную функциональность игры и настройте публикацию.

### Игра использует облачные сохранения {#field-cloud-saves}

Включите эту опцию, если игра использует методы [setData() и setStats()](https://yandex.ru/dev/games/sdk/sdk-player.md#ingame-data) у объекта `Player`.

### Отсроченная публикация {#field-delay}

Опция позволяет отложить публикацию игры. Приложение будет отправлено на модерацию, но не опубликуется после ее прохождения. Выложить игру можно будет по кнопке **Опубликовать**.

Если опция **Отсроченная публикация** включена, укажите причину приостановки публикации в поле **Комментарий к отсроченной публикации**. Причина может быть простой. Например, вы можете написать, что планируете релиз игры на определенный день.

### Комментарий разработчика {#field-comment}

Это поле увидят сотрудники модерации.

Напишите о нестандартных технических решениях или особенностях заполнения черновика. Например:
- Если прогресс не сохраняется после каждого действия пользователя или по специальной кнопке и вы используете [другие механики сохранения](https://yandex.ru/dev/games/requirements/1/9).
- Если вы не хотите монетизировать игру, напишите, что [монетизация через РСЯ](https://yandex.ru/dev/games/requirements/1/12.md) не предусмотрена и реклама в игре отсутствует.

Максимальная длина комментария — 2048.



## Шаг 4. Текстовые материалы {#description}

В разделе **Описание** добавьте текстовые материалы игры, которые будут использоваться в каталоге и поисковой выдаче.

### Название <span class="red">*</span> {#field-title}

Название игры, которое будет отображаться в Консоли разработчика и каталоге Яндекс Игр.

Общие требования:

- Максимальная длина — 50 символов (включая знаки препинания и пробелы).

- Название должно начинаться с заглавной буквы.

- Полный или частичный капс запрещен ([пункт 8.2.1](https://yandex.ru/dev/games/concepts/requirements.md#8-2-1)).

- Название не должно содержать слова, которые вводят пользователя в заблуждение относительно условий игры ([пункт 8.2.2](https://yandex.ru/dev/games/concepts/requirements.md#8-2-2)). Например, нельзя использовать «free», «top», «best», «бесплатно», «бесплатный» и т. п.

Название на каждом языке должно быть:

- Уникальным в рамках [каталога Яндекс Игр](https://yandex.ru/games/){.external} ([пункт 5.12](https://yandex.ru/dev/games/concepts/requirements.md#5-12)).

- Одинаковым на всех материалах ([пункт 5.1.3](https://yandex.ru/dev/games/concepts/requirements.md#5-1-3)).

    {% note warning %}

    Если вы меняете название игры после публикации, обновите его на обложке и промоматериалах. После этого игра пройдет повторную модерацию.

    {% endnote %}

Вы можете:

- Локализовать название игры для каждого языка. При этом на русском языке допустимо комбинировать русские и английские слова, если английские слова — имена собственные, торговые марки, либо не переводятся на русский. Например, в русском черновике можно использовать название «Шарики 3D».

- Использовать единое название на всех языках, если это имя собственное, записанное на латинице.

### Описание для SEO {#field-seo}

Краткое описание игры, которое будет отображаться в блоке информации на странице поиска в Яндексе. Чтобы привлечь пользователя, напишите связный и понятный текст об особенностях вашей игры.

Минимальная длина текста — 50 символов; максимальная — 160 (включая знаки препинания и пробелы).

Рекомендации для написания:

- Начините с ключевого слова.
- Опишите уникальное преимущество, чтобы у пользователя появилось желание перейти по ссылке.
- Добавьте призыв к действию.
- Закончите точкой или восклицательным знаком.
- В тексте не дублируйте:

  - Заголовок.
  - Контент в игре.
  - Тексты из полей **Об игре** и **Как играть**.

- Не добавляйте специальные символы `(=/\+_` в середине текста. Можно использовать графические символы, например ✧, чтобы привлечь внимание пользователя.

### Об игре <span class="red">*</span> {#field-about}

### Скриншоты <span class="red">*</span> {#field-screenshots}

Загрузите скриншоты, которые наглядно иллюстрируют особенности игры. Эти изображения будут размещены на странице игры в каталоге.

Вы можете загрузить скриншоты двух типов — в зависимости от устройства, с которого они были сняты:

- **Мобильные**
- **Десктоп**

Чтобы загружать скриншоты разных типов, выбирайте нужный тип устройства в выпадающем списке.

Для просмотра загруженных скриншотов нажмите на любой из них, и они откроются в модальном окне.

#### Ориентация скриншотов {#field-screenshots-orientation}

Десктопные скриншоты могут быть только в альбомной ориентации.

Для мобильных скриншотов выберите ориентацию: альбомную или портретную. Загружайте только скриншоты, соответствующие выбранной [ориентации](https://yandex.ru/dev/games/doc/ru/#field-orientation). Чтобы поменять ориентацию скриншотов, сначала удалите старые материалы из поля **Добавьте скриншоты**.

#### Добавьте скриншоты <span class="red">*</span> {#field-add-screenshots}

Можно загрузить только скриншоты, соответствующие заданным параметрам:

- Пропорции для скриншотов:

  - Альбомной ориентации — 16 × 9.
  - Портретной ориентации — 9 × 16.

- Размер — от 1280 до 2560 пикселей (по длинной стороне).
- Формат — JPEG или 24-разрядный PNG.

{% note warning %}

Убедитесь, что скриншоты демонстрируют реальный геймплей игры, который занимает не менее 70% изображения ([пункт 5.1.1.2](https://yandex.ru/dev/games/concepts/requirements.md#5-1-1-2)).

{% endnote %}

Нужно загрузить как минимум по 2 скриншота для каждой выбранной платформы (**Мобильные**, **Десктоп**).
