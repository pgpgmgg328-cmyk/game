## Наборы языков {#languages}

Минимальный рекомендуемый набор языков для привлечения в игру наибольшего объема трафика:
- русский;
- турецкий;
- английский.

Резервный набор языков на случай, если основной язык не поддерживается на стороне пользователя:
- **ru** для **be, kk, uk, uz**;
- **en** для остальных языков.

Если вы размещаете игру на своем домене, и у вас включен [CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy/frame-ancestors){.external}, то необходимо, чтобы игра корректно открывалась на всех вышеперечисленных доменах.

Помимо основных доменов, рекомендуем добавить wildcard для поддоменов `*.yandex.{tld}`, где `{tld}` — все перечисленные выше домены.


## AI-описания {#ai-descriptions}

**AI-описания** — это функция автоматического создания описаний игр на разных языках. Она упрощает публикацию проектов на других языках и помогает:

- привлечь больше органического трафика от иностранных пользователей;
- увеличить доход от ваших проектов.

{% note info %}

AI-описания переводят только карточку игры. Все тексты внутри игры (интерфейс, меню, диалоги и т. д.) нужно локализовать самостоятельно.

{% endnote %}

### Подключение {#enable}

{% note warning %}

Возможность подключить AI-описания доступна, пока нет опубликованной версии игры.

{% endnote %}

1. Создайте [черновик](https://yandex.ru/dev/games/doc/console/add-new-game.md#step-create-draft) с описанием на английском языке.
2. На вкладке **Черновик** внизу страницы оставьте включенной опцию **Хочу подключить AI-описания**.
3. Пройдите [модерацию](https://yandex.ru/dev/games/doc/ru/moderation.md).

После публикации игры на вкладке **AI-описания** появятся переводы на другие языки. Для просмотра выберите нужный язык из выпадающего списка (по умолчанию — английский).

{% note tip %}

 Если варианты перевода не подходят, на вкладке **AI-описания** нажмите **Сделать новые AI-описания** или добавьте язык в черновик вручную.

{% endnote %}

### Работа AI-описаний {#work-principle}

Языковые черновики добавлять вручную не нужно — система автоматически создает переводы на основе английского описания. Нейросеть:

- адаптирует текст для каждого языка;
- сохраняет смысл;
- делает текст более подходящим для продвижения на разных рынках.

AI-описания повышают видимость игры в каталоге: даже если игра переведена только на русский и английский, ее смогут увидеть все международные игроки. Информационная карточка игры будет отображаться на языке каталога. Если игра не поддерживает выбранный язык каталога, она будет запущена на [резервном](https://yandex.ru/dev/games/doc/ru/#languages).

{% note info %}

Если у вас уже есть собственные описания на выбранных языках, будут показаны они. Если нет&nbsp;— AI-описания.

{% endnote %}

Чтобы отключить AI-описания, напишите в [чат поддержки](https://yandex.ru/chat/#/user/774df508-c12d-9d6e-6a27-5e3fc522016a){.external}.
