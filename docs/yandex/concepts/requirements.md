# Требования к игре







На странице описаны особенности требований к играм, хранящимся в [каталоге Яндекс Игры](https://yandex.ru/games/){.external}.

Проверка игр производится на окружениях, приближенных к пользовательским. Отсутствие найденного замечания на устройстве разработчика не является обоснованием для снятия замечания.

{% note info %}

Прохождение модерации не означает и не должно толковаться как заверение или иное подтверждение Яндекса в отношении соответствия игры требованиям законодательства какой-либо территории и/или отсутствия в отношении нее каких-либо нарушений прав или законных интересов третьих лиц.

{% endnote %}

Игру проверят на соответствие [требованиям](https://yandex.ru/dev/games/doc/ru/requirements.md). Обычно [модерация](https://yandex.ru/dev/games/doc/ru/moderation.md) занимает 3–5 рабочих дней.

Дата последнего изменения: 22 сентября 2026 года.

## Технические требования {#1}

<p class="hidden-text">Раздел 1.</p>

1. <span class="hidden-text">Пункт 1.1.</span> В игру встроен [SDK Яндекс Игр](https://yandex.ru/dev/games/doc/sdk/sdk-about.md). {#1-1}
2. <span class="hidden-text">Пункт 1.2.</span> Для запуска и использования игры не требуется регистрация или авторизация на сторонних сервисах. Допустима только авторизация с Яндекс ID, которую можно запросить через [SDK Яндекс Игр](https://yandex.ru/dev/games/doc/sdk/sdk-player.md#auth). [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/2.md#auth-add). {#1-2}

    1. <span class="hidden-text">Пункт 1.2.1.</span> Авторизация происходит только после осознанного действия пользователя — нажатия специальной кнопки внутри игры. В предложении авторизации указано, какие преимущества она дает. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/2.md#auth-offer). {#1-2-1}

    2. <span class="hidden-text">Пункт 1.2.2.</span> Реализован гостевой вход или возможность игры без авторизации. Прогресс игрока при этом сохраняется. {#1-2-2}

3. <span class="hidden-text">Пункт 1.3.</span> При потере фокуса звук из игры останавливается. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/3.md). {#1-3}
4. <span class="hidden-text">Пункт 1.4.</span> Платежи производятся только через [SDK Яндекс Игр](https://yandex.ru/dev/games/doc/sdk/sdk-purchases.md). Отсутствуют микротранзакции и любые внешние покупки. {#1-4}
5. <span class="hidden-text">Пункт 1.5.</span> (Упразднен, см. [пункт 4.1](https://yandex.ru/dev/games/doc/ru/#4-1).) {#1-5 .deprecated}
6. <span class="hidden-text">Пункт 1.6.</span> Игра должна соответствовать требованиям к тем видам устройств, которые указаны в заявке на публикацию. {#1-6}

    1. <span class="hidden-text">Пункт 1.6.1.</span> Для мобильных устройств: {#1-6-1}

        1. <span class="hidden-text">Пункт 1.6.1.1.</span> Игра находится в полноэкранном режиме во время игрового процесса или запуска. {#1-6-1-1}

        2. <span class="hidden-text">Пункт 1.6.1.2.</span> Если есть возможность ввода данных (например, никнейма игрока), клавиатура автоматически показывается при нажатии на поле ввода. {#1-6-1-2}

        3. <span class="hidden-text">Пункт 1.6.1.3.</span> (Упразднен, см. [пункт 1.10](https://yandex.ru/dev/games/doc/ru/#1-10).) {#1-6-1-3 .deprecated}

        4. <span class="hidden-text">Пункт 1.6.1.4.</span> (Упразднен.) {#1-6-1-4 .deprecated}

        5. <span class="hidden-text">Пункт 1.6.1.5.</span> Игра полностью управляется жестами. Механики управления можно дополнить использованием акселерометра мобильного устройства. {#1-6-1-5}

        6. <span class="hidden-text">Пункт 1.6.1.6.</span> В любых браузерах не отображается системный плеер, вызываемый игрой. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/6.md). {#1-6-1-6}

        7. <span class="hidden-text">Пункт 1.6.1.7.</span> Отсутствует уведомление о [WebGL](https://yandex.ru/dev/games/doc/ru/*WebGL) при открытии игры. {#1-6-1-7}

        8. <span class="hidden-text">Пункт 1.6.1.8.</span> [Лонгтап](https://yandex.ru/dev/games/doc/ru/*longtap) по внутреннему полю игры не приводит к выделению поля или открытию контекстного меню. [Подробнее](https://stackoverflow.com/questions/826782/how-to-disable-text-selection-highlighting){.external}. {#1-6-1-8}

    2. <span class="hidden-text">Пункт 1.6.2.</span> Для десктопных устройств: {#1-6-2}

        1. <span class="hidden-text">Пункт 1.6.2.1.</span> Активное поле растягивается по вертикали или горизонтали до края доступной области (без учета стики-баннеров). {#1-6-2-1}

        2. <span class="hidden-text">Пункт 1.6.2.2.</span> Длинная сторона активного поля превосходит короткую не более чем в два раза. {#1-6-2-2}

        3. <span class="hidden-text">Пункт 1.6.2.3.</span> (Упразднен, см. [пункт 1.10](https://yandex.ru/dev/games/doc/ru/#1-10).) {#1-6-2-3 .deprecated}

        4. <span class="hidden-text">Пункт 1.6.2.4.</span> Игрой можно управлять с помощью клавиатуры или мыши по умолчанию. При этом управление не зависит от раскладки. {#1-6-2-4}

        5. <span class="hidden-text">Пункт 1.6.2.5.</span> В любых браузерах не отображается системный плеер, вызываемый игрой. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/6.md). {#1-6-2-5}

        6. <span class="hidden-text">Пункт 1.6.2.6.</span> В игре не используются сочетания клавиш, зарезервированные операционной системой или другими приложениями. {#1-6-2-6}

        7. <span class="hidden-text">Пункт 1.6.2.7.</span> Взаимодействие с внутренним полем игры не приводит к его выделению или открытию контекстного меню. {#1-6-2-7}

    3. <span class="hidden-text">Пункт 1.6.3.</span> Для телевизоров ([подробнее](https://yandex.ru/dev/games/doc/requirements/1/6/3.md)): {#1-6-3}

        1. <span class="hidden-text">Пункт 1.6.3.1.</span> Игра занимает всю площадь экрана, доступен полноэкранный режим. {#1-6-3-1}

        2. <span class="hidden-text">Пункт 1.6.3.2.</span> Поддерживается управление с помощью стрелок на ТВ-пульте. Для полноценного прохождения игры достаточно управления стрелками пульта. {#1-6-3-2}

        3. <span class="hidden-text">Пункт 1.6.3.3.</span> Игра обрабатывает события кнопок **Back** и **ОК** на ТВ-пульте. {#1-6-3-3}

        4. <span class="hidden-text">Пункт 1.6.3.4.</span> Отсутствуют инап-покупки. {#1-6-3-4}

        5. <span class="hidden-text">Пункт 1.6.3.5.</span> Нет ссылок на другие игры разработчика. {#1-6-3-5}

7. <span class="hidden-text">Пункт 1.7.</span> Для корректной работы из любой точки мира в программном коде не используются абсолютные URL, ссылающиеся на серверы S3 Яндекса. {#1-7}
8. <span class="hidden-text">Пункт 1.8.</span> Интерактивные элементы игры адаптированы под размер экрана и удобны для взаимодействия. {#1-8}
9. <span class="hidden-text">Пункт 1.9.</span> В играх с прогрессом (новые открытые уровни, рекорды, достижения, улучшения) изменения сохраняются сразу после действия игрока или по специальной кнопке. После обновления страницы или смены ориентации экрана на мобильном устройстве прогресс не теряется. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/9.md). {#1-9}

10. <span class="hidden-text">Пункт 1.10.</span> Игра корректно отображается, в том числе при изменении размера окна и при повороте экрана: {#1-10}

    1. <span class="hidden-text">Пункт 1.10.1.</span> Элементы не обрезаются и не выходят за рамки экрана. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/10.md#cut). {#1-10-1}

    2. <span class="hidden-text">Пункт 1.10.2.</span> Отсутствует браузерная прокрутка страницы (системный скроллбар окна браузера) или swipe-to-refresh. При этом допустимо реализовать собственную прокрутку контента средствами игры. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/10.md#scroll-swipe). {#1-10-2}

    3. <span class="hidden-text">Пункт 1.10.3.</span> Элементы и тексты не накладываются друг на друга и не перекрывают другие элементы. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/10.md#overlap). {#1-10-3}

    4. <span class="hidden-text">Пункт 1.10.4.</span> Игрой можно управлять одной рукой. Основной игровой экран не требует прокрутки или смахиваний — все нужные элементы видны и доступны сразу. Исключение: в стратегиях, RPG и других жанрах с большим игровым полем его допустимо перемещать. {#1-10-4}

11. <span class="hidden-text">Пункт 1.11.</span> Если игра использует облачные сохранения, в черновике включена опция [Игра использует облачные сохранения](https://yandex.ru/dev/games/doc/console/add-new-game/draft.md#field-cloud-saves). {#1-11}
12. <span class="hidden-text">Пункт 1.12.</span> Подключена монетизация: в игре есть реклама или инап-покупки. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/12.md). {#1-12}
13. <span class="hidden-text">Пункт 1.13.</span> Для внутренних покупок: {#1-13}

    1. <span class="hidden-text">Пункт 1.13.1.</span> Подключен [метод консумирования](https://yandex.ru/dev/games/doc/sdk/sdk-purchases.md#check-purchases). [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/13.md#consummation). {#1-13-1}

    2. <span class="hidden-text">Пункт 1.13.2.</span> Портальная валюта определяется автоматически: название и иконка берутся из [SDK Яндекс Игр](https://yandex.ru/dev/games/doc/sdk/sdk-purchases.md#product-characteristics). [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/13.md#currency-detection). {#1-13-2}

    3. <span class="hidden-text">Пункт 1.13.3.</span> Прогресс игры сохраняется на сервере и доступен для одного пользователя с разных устройств. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/13.md#purchases-save). {#1-13-3}

    4. <span class="hidden-text">Пункт 1.13.4.</span> Все покупки внутри игры имеют обозначенную цифрами стоимость и указание портальной валюты. {#1-13-4}

    5. <span class="hidden-text">Пункт 1.13.5.</span> Описание покупки в игре (изображение, название, состав и характеристики) соответствует тому, что приобретает пользователь. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/13.md#purchase-correct). {#1-13-5}

    6. <span class="hidden-text">Пункт 1.13.6.</span> Список покупок в игре соответствует информации в [Консоли разработчика](https://games.yandex.ru/console){.external}: {#1-13-6}
        - Если на вкладке **Инап-покупки** есть активные покупки, они присутствуют в игре.
        - Если вкладка **Инап-покупки** пустая или покупки на ней неактивны, они отсутствуют в игре.

14. <span class="hidden-text">Пункт 1.14.</span> Игра работает без технических ошибок, зависаний и вылетов как в ходе обычного геймплея, так и при различных действиях: повороте экрана, длительном нажатии, жестах, сворачивании браузера, показе рекламы, переходам по истории браузера и других. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/14.md). {#1-14}
15. <span class="hidden-text">Пункт 1.15.</span> Игра имеет завершенный вид и не находится в процессе разработки или предварительного тестирования. Реализованы все элементы, необходимые для игрового процесса: тексты, графика, управление и игровые механики. [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/15.md). {#1-15}
16. <span class="hidden-text">Пункт 1.16.</span> Отсутствуют модификации контента и внешнего вида встраиваемых рекламных блоков. Запрещено имитировать рекламные блоки сервиса, например создавать кастомные полноэкранные блоки или [RV](https://yandex.ru/dev/games/doc/ru/*RewardedVideo) со своими кнопками. {#1-16}
17. <span class="hidden-text">Пункт 1.17.</span> (Упразднен.) {#1-17 .deprecated}
18. <span class="hidden-text">Пункт 1.18.</span> Работа игры не ограничена из-за URL, на котором она открыта. {#1-18}
19. <span class="hidden-text">Пункт 1.19.</span> SDK Яндекс Игр инициализируется и используется в соответствии с документацией: {#1-19}

    1. <span class="hidden-text">Пункт 1.19.1.</span> SDK инициализируется строго так, как указано на странице [Подключение и использование](https://yandex.ru/dev/games/doc/sdk/sdk-about.md). [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/19.md#sdk-initializing). {#1-19-1}

    2. <span class="hidden-text">Пункт 1.19.2.</span> В момент, когда пользователь может приступить к игре, вызывается метод `LoadingAPI.ready()` из [Game Ready](https://yandex.ru/dev/games/doc/sdk/sdk-game-events.md#gameready). [Подробнее](https://yandex.ru/dev/games/doc/requirements/1/19.md#gameready). {#1-19-2}

    3. <span class="hidden-text">Пункт 1.19.3.</span> Если в игре есть разметка геймплея, моменты вызова методов `GameplayAPI.start()` и `GameplayAPI.stop()` соответствуют описанным в разделе [Геймплей](https://yandex.ru/dev/games/doc/sdk/sdk-game-events.md#gameplay). {#1-19-3}

    4. <span class="hidden-text">Пункт 1.19.4.</span> Если в игре используются методы `ysdk.on()` и `ysdk.off()` для отслеживания событий `game_api_pause` и `game_api_resume`, логика их обработки соответствует описанной в разделе [Пауза и возобновление игры](https://yandex.ru/dev/games/doc/sdk/sdk-events.md#pause-resume). {#1-19-4}

20. <span class="hidden-text">Пункт 1.20.</span> Игра корректно запускается в браузерах и на платформах, которые подходят под выбранное в черновике [окружение](https://yandex.ru/dev/games/doc/console/add-new-game/draft.md#field-supported-platforms): {#1-20}

    1. <span class="hidden-text">Пункт 1.20.1.</span> В браузерах: Яндекс Браузер, Google Chrome, Mozilla Firefox, Opera, Safari, мобильном приложении Яндекс. {#1-20-1}

    2. <span class="hidden-text">Пункт 1.20.2.</span> В операционных системах: Windows Vista, Windows 7, Windows 8, Windows 10, Mac OS X 10.6 и выше (Snow Leopard, Lion, Mountain Lion, Mavericks, Yosemite, El Capitan, Sierra, High Sierra и Mojave). {#1-20-2}

    3. <span class="hidden-text">Пункт 1.20.3.</span> В мобильных операционных системах: Android 5.0 и выше, iOS 9.0 и выше. {#1-20-3}

    4. <span class="hidden-text">Пункт 1.20.4.</span> На Android TV. {#1-20-4}

21. <span class="hidden-text">Пункт 1.21.</span> Размер всех файлов игры не превышает 100 МБ в разархивированном виде. {#1-21}
22. <span class="hidden-text">Пункт 1.22.</span> В корень архива добавлен файл `index.html`. В названиях файлов и папок не используются пробелы и русские символы. {#1-22}
23. <span class="hidden-text">Пункт 1.23.</span> В играх запрещен интерактивный искусственный интеллект (ИИ). При этом допустимо использовать материалы, которые были заранее сгенерированы с помощью ИИ. {#1-23}
24. <span class="hidden-text">Пункт 1.24.</span> Новые версии игры сохраняют ее основную концепцию. Запрещено загружать в качестве обновления совершенно другую игру. {#1-24}



## Требования к пользовательскому опыту {#2}

<p class="hidden-text">Раздел 2.</p>

1. <span class="hidden-text">Пункт 2.1.</span> Игра проработана с точки зрения содержания, удобства и игрового процесса. Сервис проводит внутренний контроль качества и вправе отказать в публикации, если игра не соответствует общим стандартам платформы. {#2-1}
2. <span class="hidden-text">Пункт 2.2.</span> Внутри игры или в черновике в поле [Как играть](https://yandex.ru/dev/games/doc/console/add-new-game/draft.md#field-how-to-play) полностью описано управление. {#2-2}
3. <span class="hidden-text">Пункт 2.3.</span> Игра соответствует заявленному в черновике [жанру](https://yandex.ru/dev/games/doc/console/add-new-game/draft.md#field-category). {#2-3}
4. <span class="hidden-text">Пункт 2.4.</span> Игра соответствует минимум одному из критериев наличия игровых механик. [Подробнее](https://yandex.ru/dev/games/doc/requirements/2/4.md). {#2-4}
5. <span class="hidden-text">Пункт 2.5.</span> (Упразднен, см. [пункт 6](https://yandex.ru/dev/games/doc/ru/#6).) {#2-5 .deprecated}
6. <span class="hidden-text">Пункт 2.6.</span> (Упразднен, см. [пункт 1.9](https://yandex.ru/dev/games/doc/ru/#1-9).) {#2-6 .deprecated}
7. <span class="hidden-text">Пункт 2.7.</span> Содержание игры соответствует заявленному в черновике [возрастному рейтингу](https://yandex.ru/dev/games/doc/console/add-new-game/draft.md#field-age-rating). [Подробнее](https://yandex.ru/dev/games/doc/requirements/2/7.md). {#2-7}
8. <span class="hidden-text">Пункт 2.8.</span> Игра имеет нарастающую сложность и понятный сюжет или сеттинг. {#2-8}
9. <span class="hidden-text">Пункт 2.9.</span> Прохождение основного содержания игры занимает более 10 минут, или у пользователя есть мотивация перепроходить ее. [Подробнее](https://yandex.ru/dev/games/doc/requirements/2/9.md). {#2-9}
10. <span class="hidden-text">Пункт 2.10.</span> (Упразднен, см. [пункт 8.2.3](https://yandex.ru/dev/games/doc/ru/#8-2-3).) {#2-10 .deprecated}
