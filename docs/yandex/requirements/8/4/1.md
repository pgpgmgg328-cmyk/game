# Ссылки на другие игры







{% note info "Пункт 8.4.1 Требований к игре" %}

Ссылки в текстах и медиаматериалах [встроены через SDK](https://yandex.ru/dev/sdk/sdk-other-games.md) и ведут на ваши игры в каталоге Яндекс Игр. Переход на другие игры не прерывает игровой процесс, а [элементы навигации](https://yandex.ru/dev/games/doc/ru/*examples_navigation) очевидны для пользователей.

{% endnote %}

## Критерии прохождения модерации {#criteria}

- Ссылки встроены через SDK и ведут на ваши игры в каталоге Яндекс Игр.
- По элементам навигации понятно, куда они приведут пользователя.
- Перейти к другим играм можно только вне активного геймплея (например, в меню или между уровнями).
- При переходе на другие игры текущая вкладка с игрой не закрывается.

## Методика проверки {#verification}

Чтобы убедиться, что ссылки встроены через SDK:

1. Очистите [кеш](https://yandex.ru/support/common/ru/browsers-settings/cache){.external}.
1. Откройте игру с [debug-панелью](https://yandex.ru/dev/console/debug-panel.md):

   {% list tabs %}

   - Через Консоль разработчика
       1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console){.external}.
       1. Выберите нужную игру.
       1. В левом верхнем углу нажмите **Открыть с debug-панелью**.

   - Через адресную строку
       1. Откройте нужную игру.
       1. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

          Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.

   {% endlist %}

1. В левом нижнем углу экрана нажмите кнопку **SDK mocks** ⚒️ и выберите опцию 🔗 **Game links mock is enabled**.

   {% cut "Как это выглядит" %}

   ![Скриншот игры, открытой с debug-панелью: нажата кнопка с иконкой скрещенных молотка и кирки, над debug-панелью всплывающее меню, стрелка указывает на опцию Game links mock is disabled.](https://yandex.ru/dev/_images/requirements/8-4-1-links-to-other-games/disabled.webp%20=250x)

   {% endcut %}

1. Подождите 5 секунд.
1. Перезагрузите игру.
1. Перейдите по ссылке на другую вашу игру.

   Если API используется правильно, откроется статическая страница:

   ![Скриншот адресной строки браузера: название вкладки — «app-374241.games.s3.y», текст в адресной строке — «https://app-374241.games.s3.yandex.net/helpers/fake-page», текст в открытой вкладке — «Hi».](https://yandex.ru/dev/_images/requirements/8-4-1-links-to-other-games/static-page.webp)

   Если откроется другая страница (например, страница с другими играми), значит ссылки на другие игры добавлены неправильно. В этом случае обратитесь к [инструкции по добавлению ссылок](https://yandex.ru/dev/sdk/sdk-other-games.md).
