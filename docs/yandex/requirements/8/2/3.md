# Переводы текстов







{% note info "Пункт 8.2.3 Требований к игре" %}

Тексты, которые меняются в зависимости от языка и имеют значение для игрового процесса, переведены на соответствующий язык.

{% endnote %}

Приложение должно быть понятно для пользователей, которые разговаривают на разных языках. Поэтому [нужно переводить](https://yandex.ru/dev/games/doc/ru/#translated) важные для игрового процесса тексты: элементы управления, обучение, настройки. Фразы, которые понятны игрокам вне зависимости от их родного языка, можно оставить [без перевода](https://yandex.ru/dev/games/doc/ru/#not-translated).

## Нужен перевод {#translated}

- [Внутриигровая валюта](https://yandex.ru/dev/games/doc/ru/#currency): золотые монеты, драгоценные камни и т. д.
- [Все кнопки и игровые элементы](https://yandex.ru/dev/games/doc/ru/#buttons), с которыми взаимодействует игрок, например: **Уровень**, **Купить**, **Введите имя**.
- [Геймплейные тексты](https://yandex.ru/dev/games/doc/ru/#gameplay-texts), такие как: **Конец игры**, **Лучший счет**, **День**, **Выход**.
- [Предупреждения о рекламе](https://yandex.ru/dev/games/doc/ru/#advertisement): **Пауза**, **Реклама**, текст предупреждения.
- [Описание управления](https://yandex.ru/dev/games/doc/ru/#controlling), например, **Нажмите E**.
- [Двойной перевод](https://yandex.ru/dev/games/doc/ru/#double-translation) недопустим: текст в игре должен соответствовать выбранному языку.
- [Название языка](https://yandex.ru/dev/games/doc/ru/#language-naming) на другом языке.

## Не нужен перевод {#not-translated}

- [Сокращения и аббревиатуры](https://yandex.ru/dev/games/doc/ru/#abbreviation) вне зависимости от регистра, например ad, OK, VIP, стороны света, am/pm.
- [Названия клавиш](https://yandex.ru/dev/games/doc/ru/#keyboard): Ctrl, Alt, Shift и&nbsp;т.&nbsp;д.
- [Имена собственные без официального перевода](https://yandex.ru/dev/games/doc/ru/#naming): ники игроков, торговые марки, названия приложений, программ, компаний.
- [Окружение](https://yandex.ru/dev/games/doc/ru/#environment): тексты, с которыми не взаимодействует игрок и которые не важны для геймплея. К таким относятся логотипы, слоганы, названия игровых движков (powered by unity), фоновые изображения (вывеска магазина, надписи на зданиях), названия песен, твиты.
- [Эффекты окружения](https://yandex.ru/dev/games/doc/ru/#effects): визуализация комикс-эффектов, которые не нужны для понимания происходящего в игре. Например, графическое отображение звуков ( «pain», «crack»), вскриков («ouch!», «oh!») и другого («combo», «great!»).
- [Некоторые символы](https://yandex.ru/dev/games/doc/ru/#symbols) у которых обычно нет перевода, например: операторы языков программирования, математические функции, обозначения химических элементов, аккорды, @, &.
- [Название языка](https://yandex.ru/dev/games/doc/ru/#language-naming-ok) в окне выбора локализации игры должно быть написано на этом языке: Русский, English, Türkçe.
- [Дополнения к элементам интерфейса](https://yandex.ru/dev/games/doc/ru/#common-words): общеизвестные слова, вшитые в элементы пользовательского интерфейса. Например: NEW, SALE, FREE.
- [Названия жанров](https://yandex.ru/dev/games/doc/ru/#genres): RPG, idle, action, clicker и&nbsp;т.&nbsp;д.

{% note warning %}

Коды реально существующих валют (USD, RUB и т. п.) переводить не надо.

Если в игре есть покупки, возьмите название и иконку портальной валюты из [SDK](https://yandex.ru/dev/sdk/sdk-purchases.md#product-characteristics) (пункт 1.13.2), а не добавляйте вручную. Подробнее см. в разделе [Автоматическое определение портальной валюты](https://yandex.ru/dev/games/1/13.md#currency-detection).

{% endnote %}
