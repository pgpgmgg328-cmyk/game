# Технические ошибки







{% note info "Пункт 1.14 Требований к игре" %}

Игра работает без технических ошибок, зависаний и вылетов как в ходе обычного геймплея, так и при различных действиях: повороте экрана, длительном нажатии, жестах, сворачивании браузера, показе рекламы, переходах по истории браузера и других.

{% endnote %}

Игра должна работать правильно:

- Корректно [загружаться](https://yandex.ru/dev/games/doc/ru/#loading).
- Не [зависать](https://yandex.ru/dev/games/doc/ru/#lags), в том числе не содержать экранов-тупиков, из которых нельзя перейти в другое окно, возобновить игру или начать новую.
- Не содержать [технических надписей](https://yandex.ru/dev/games/doc/ru/#text), всплывающих текстов.
- Не вызывать [ошибок](https://yandex.ru/dev/games/doc/ru/#errors) и браузерных уведомлений.
