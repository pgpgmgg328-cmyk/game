# Авторизация







{% note info "Пункт 1.2 Требований к игре" %}

Для запуска и использования игры не требуется регистрация или авторизация на сторонних сервисах. Допустима только авторизация с Яндекс ID, которую можно запросить через [SDK Яндекс Игр](https://yandex.ru/dev/games/sdk/sdk-player.md#auth).

1. Авторизация происходит только после осознанного действия пользователя — нажатия специальной кнопки внутри игры. В предложении авторизации указано, какие преимущества она дает.

2. Реализован гостевой вход или возможность игры без авторизации. Прогресс игрока при этом сохраняется.

{% endnote %}


## Добавление авторизации {#auth-add}

**1.2.** Для запуска и использования игры не требуется регистрация или авторизация на сторонних сервисах. Допустима только авторизация с Яндекс ID.

Почему это важно: без обязательной регистрации или авторизации пользователь быстрее начнет играть, игра — приносить доход. К тому же у такой игры будет ниже порог вхождения, а значит, и больше пользователей.

Если вы добавили авторизацию в свою игру, то придерживайтесь следующих правил:

- Пользователь может играть без регистрации и авторизации.
- Авторизация может быть только с Яндекс ID.
- В сообщении, которое предлагает авторизацию, есть пояснение, какие преимущества она даст пользователю.
- В игре нет предложений авторизации:

    - на сторонних сервисах;
    - если пользователь уже вошел в аккаунт.

## Предложение авторизации {#auth-offer}

**1.2.1.** Авторизация происходит только после осознанного действия пользователя.

Авторизация должна быть предсказуемой, чтобы не мешать пользователю и не вызывать у него недовольство. Помимо этого, у пользователя должна быть информация, какие преимущества он получит благодаря авторизации.

Чтобы авторизация была комфортной для пользователя, следуйте правилам:

- Переход на страницу авторизации происходит, только если пользователь сам осознанно выбрал это действие (например, нажал кнопку с текстом «Авторизоваться»).
- Предложение авторизоваться выводится с пояснением, какие у пользователя будут при этом преимущества, например:
    - Сохранение прогресса в облаке.
    - Уведомления о новинках и акциях.
    - Инап-покупки — купленные предметы и улучшения будут доступны в любом браузере, а не только в текущем.
- Пользователь может отказаться от авторизации и продолжить играть.
