# Методы SDK







{% note info "Пункт 1.19 Требований к игре" %}

SDK Яндекс Игр инициализируется и используется в соответствии с документацией:

1. SDK инициализируется строго так, как указано на странице [Подключение и использование](https://yandex.ru/dev/games/sdk/sdk-about.md).

2. В момент, когда пользователь может приступить к игре, вызывается метод `LoadingAPI.ready()` из [Game Ready](https://yandex.ru/dev/games/sdk/sdk-game-events.md#gameready).

3. Если в игре есть разметка геймплея, моменты вызова методов `GameplayAPI.start()` и `GameplayAPI.stop()` соответствуют описанным в разделе [Геймплей](https://yandex.ru/dev/games/sdk/sdk-game-events.md#gameplay).

4. Если в игре используются методы `ysdk.on()` и `ysdk.off()` для отслеживания событий `game_api_pause` и `game_api_resume`, логика их обработки соответствует описанной в разделе [Пауза и возобновление игры](https://yandex.ru/dev/games/sdk/sdk-events.md#pause-resume).

{% endnote %}

## Инициализация SDK {#sdk-initializing}

**1.19.1.** SDK инициализируется строго так, как указано на странице [Подключение и использование](https://yandex.ru/dev/games/sdk/sdk-about.md). Чтобы требование считалось выполненным, должен использоваться актуальный лоадер.

### Проверка актуальности лоадера {#loader-check}

1. Запустите игру с debug-панелью.

    {% list tabs %}

    - Через Консоль разработчика
        1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console){.external}.
        1. Выберите нужную игру.
        1. В левом верхнем углу нажмите **Открыть с debug-панелью**.

    - Через адресную строку
        1. Откройте нужную игру.
        1. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

           Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.

    {% endlist %}

1. На debug-панели слева от индикатора Game Ready найдите две буквы:
    - `IF` (init false) — игра поддерживает старый лоадер. При наведении указателя на `IF` появится надпись _Is loader: false_.

    - `IT` (init true) — игра поддерживает новый лоадер. При наведении указателя на `IT` появится надпись _Is loader: true_.

## Game Ready {#gameready}

**1.19.2.** Когда пользователь уже может начать игру, вызовите метод `LoadingAPI.ready()` из [Game Ready](https://yandex.ru/dev/games/sdk/sdk-game-events.md#gameready).

Чтобы требование считалось выполненным, метод `LoadingAPI.ready()` должен вызываться в [корректный момент](https://yandex.ru/dev/games/doc/ru/#gameready-correct).

### Загрузочный экран {#loading-screen}

Во время загрузки игры платформа Яндекс Игры вначале показывает свой загрузочный экран — пульсирующую иконку игры и надпись «Загрузка». Его можно скрыть вручную, если нажать на экран.

{% cut "Как выглядит загрузочный экран Яндекс Игр" %}

![Загрузочный экран Яндекс Игр: пульсирующая иконка игры и надпись «Загрузка»](https://yandex.ru/dev/games/_images/requirements/1-19-sdk-methods/gra/yandex-games-loading.webp)

{% endcut %}

Модерация проверяет загрузочный экран самой игры. Если на нем есть запрещенный контент — сторонние ссылки, чужие логотипы, элементы, нарушающие авторские права, — это станет основанием для отказа.

### Подготовка {#gameready-preparation}

1. Запустите игру с debug-панелью.

    {% list tabs %}

    - Через Консоль разработчика
        1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console){.external}.
        1. Выберите нужную игру.
        1. В левом верхнем углу нажмите **Открыть с debug-панелью**.

    - Через адресную строку
        1. Откройте нужную игру.
        1. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

           Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.

    {% endlist %}

1. На debug-панели найдите индикатор Game Ready ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gra-purple.svg).

### Логика проверки Game Ready {#gameready-check}

1. Проверьте, что фиолетовый индикатор ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gra-purple.svg) сменился на зеленый ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gra-green.svg) в течение 90 секунд.
1. Перезагрузите игру.
1. Повторно проверьте, в какой момент индикатор меняет цвет.

Модерация проверяет, что:

- индикатор меняет цвет, когда игра становится доступна;
- и загрузочный экран не пропускается кликом.

![Видео загрузки игры: загрузочный экран Яндекс Игр исчезает автоматически, затем на короткое время отображается загрузочный экран игры, после чего игра становится доступна для взаимодействия, и одновременно с этим индикатор становится зеленым.](https://yandex.ru/dev/games/_images/requirements/1-19-sdk-methods/gra/with-yandex-games-loading.gif)

{% note info %}

Чтобы игра прошла модерацию, Game Ready должен работать корректно: вызов `LoadingAPI.ready()` нужно привязать к реальной готовности игры, а не к конкретному моменту времени.

{% endnote %}

### Game Ready подключен и работает корректно {#gameready-correct}

Фиолетовый индикатор ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gra-purple.svg) сменился на зеленый ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gra-green.svg), когда:

- Начинается [взаимодействие с игрой](https://yandex.ru/dev/games/doc/ru/#gameready-correct-interaction):
    - Становится доступно управление (в том числе мини-игрой, пока продолжается загрузка).
    - Открывается меню или появляется надпись «Нажмите, чтобы начать».
    - Начинается обратный отсчет.
- Появляется [всплывающее окно](https://yandex.ru/dev/games/doc/ru/#gameready-correct-pop-up) (например, с политикой конфиденциальности, лицензионным соглашением, предложением авторизоваться или ежедневным бонусом).
- Начинается [неинтерактивный элемент](https://yandex.ru/dev/games/doc/ru/#gameready-correct-not-interaction) игры (кат-сцена, диалог, стартовая анимация и т. д.).
- Становятся доступны [настройки](https://yandex.ru/dev/games/doc/ru/#gameready-correct-settings) (графики, управления и т. д.), создание или выбор персонажа, карты или уровня.

## Разметка геймплея {#gameplay}

**1.19.3.** Методы `GameplayAPI.start()` и `GameplayAPI.stop()` позволяют размечать начало и остановку игрового процесса. Если они используются в игре, то моменты отправки событий строго соответствуют описанным в разделе [Геймплей](https://yandex.ru/dev/games/sdk/sdk-game-events.md#gameplay).

### Подготовка {#gameplay-preparation}

1. Запустите игру с [debug-панелью](https://yandex.ru/dev/games/console/debug-panel.md).

    {% list tabs %}

    - Через Консоль разработчика
        1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console){.external}.
        1. Выберите нужную игру.
        1. В левом верхнем углу нажмите **Открыть с debug-панелью**.

    - Через адресную строку
        1. Откройте нужную игру.
        1. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

           Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.

    {% endlist %}

2. На debug-панели найдите кнопку геймпада 🎮.

### Проверка разметки геймплея {#gameplay-check-principle}

Отслеживайте состояние индикатора геймплея в зависимости от действий:

- Когда игрок начинает игровой процесс или возобновляет его после паузы, должен быть вызван метод `GameplayAPI.start()`. Индикатор геймплея должен стать зеленым ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gameplay-on.svg) — геймплей в процессе.

- Когда игрок завершает игровой процесс или приостанавливает его, должен быть вызван метод `GameplayAPI.stop()`. Индикатор геймплея должен стать красным ![SVG](https://yandex.ru/dev/games/_images/debug-panel/gameplay-off.svg) — геймплей на паузе.

Сценарии, которые модерация учитывает при проверке:

- Запуск и завершение уровня.
- Открытие и закрытие игрового меню.
- Открытие и закрытие меню покупок.
- Запуск и закрытие рекламы.
- Потеря фокуса с игры и возвращение в игру (переход на другую вкладку браузера или в другое окно).

{% note tip %}

Чтобы узнать, где находится фокус (на игре или на другом окне), отслеживайте [события](https://yandex.ru/dev/games/sdk/sdk-events.md#pause-resume) `game_api_resume` и `game_api_pause`.

{% endnote %}
