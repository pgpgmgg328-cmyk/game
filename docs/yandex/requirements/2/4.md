# Игровые механики







{% note info "Пункт 2.4 Требований к игре" %}

Игра соответствует минимум одному из критериев наличия игровых механик.

{% endnote %}

Для удержания внимания пользователей и создания увлекательного игрового процесса в игре должны быть механики, которые мотивируют ее проходить.

## Критерии {#criteria}

{% note warning %}

Требование считается выполненным, если игра удовлетворяет хотя бы одному критерию.

{% endnote %}

В игре есть:

- соревновательные механики;
- прогресс, который зависит от действий игрока (счет очков, путешествие по миру, открытие новых локаций, продвижение по сюжету);
- цель («спасти принцессу», победить соперника, пройти все уровни для открытия концовки);
- завершение (можно выиграть или проиграть).
