Снимок забега v4 хранит особые клавиши и летящий «Метеорчик».

Экран «Миры»: прогресс форм, особенности, «Играть», «Открыть за 3000 / 8000» монет или «▶ Реклама: 1 забег» (пробный забег, мир остаётся закрытым). Мир открывается сам, когда в прошлом мире вырос Пробел, — с плашкой прямо в забеге и строкой на экране результата.

Значок «!» на кнопке, пока есть что забрать.

В магазине — карточка набора и раздел «Украшения» с превью: «Выбрать», «Выбрано» или замочек с подписью, откуда украшение. - **M3 (SDK полностью) завершён.** Реклама во всех точках диздока, покупки с консумированием, магазин, стики-баннер, таблица рекордов, вход через Яндекс ID с выбором аккаунта, флаги remote config, просьба оценить игру, ярлык на рабочий стол, бот `?bot=1` и `npm run soak`. `npm run check` — 314 юнит-тестов; `npm run e2e` — 123 тестов в браузере, из них 58 новых про M3 (поддельный SDK эмулирует рекламу, покупки, вход, таблицу рекордов, флаги, отзыв и ярлык без сети); скриншоты магазина, рекордов, окон «за рекламу», «×2 монеты» и меню с ярлыком на 6 разрешениях. `npm run moderation` — 10 автоматических проверок (новая: покупки консумируются, валюта и реклама — через SDK).
- M3, площадка (`src/platform/`): `YandexPlatform` вызывает SDK строго по `docs/yandex/sdk/` — полноэкранная реклама и реклама за награду (если реклама не открылась за 8 с, игра продолжает), стики-баннер, покупки (`getPayments`, каталог, `getPurchases`, `purchase`, `consumePurchase`), вход (`openAuthDialog`, повторный `getPlayer`), окно выбора аккаунта, лидерборд (`setScore` не чаще раза в секунду, таблица кешируется на 30 с), флаги с тайм-аутом 3 с, `canReview`/`requestReview`, `canShowPrompt`/`showPrompt`. `LocalPlatform`: реклама — заглушка на 1 с (награда приходит), покупок, входа и рекордов без Яндекса нет.
- M3, реклама: на время показа игра на паузе, весь звук выключен, разметка геймплея остановлена. Полноэкранная — только по «Ещё раз» и «В меню» на экране результата, не в первые два забега, не чаще раза в 90 с (флаг `interstitialCooldownSec`, пауза считается и после рекламы за награду), никогда после покупки «Без рекламы». За награду (награда — только в колбэке `onRewarded`): «Второй шанс» при переполнении — три верхние клавиши исчезают, забег продолжается (раз за забег, флаг `secondChanceEnabled`); «+1 Встряска» и «+1 Удаление», когда заряды кончились (значок ▶ на кнопке, раз за забег каждое); «▶ ×2 монеты» на экране результата. Каждое предложение называет награду, от него можно отказаться, при ошибке кнопка говорит «Реклама пока недоступна».
- M3, покупки и магазин: при каждом запуске `getPurchases()` восстанавливает «Без рекламы» и «Набор украшений» и выдаёт оплаченные, но не выданные «1000 клацов»: выдача записывается в облако и только потом консумируется; токен хранится до консумирования, поэтому повтор никогда не выдаёт монеты дважды. Магазин показывает только товары, которые есть и в игре, и в каталоге консоли, с ценой, кодом и иконкой портальной валюты из SDK. Стики-баннер показывается через API SDK после загрузки меню и скрывается после «Без рекламы». Сохранение v4: покупки, выданные токены, «отзыв уже просили», «ярлык добавлен»; миграция с v3.
- M3, рекорды и вход: новый рекорд вошедшего игрока уходит в лидерборд `bestScore` в конце забега и сразу после входа. Экран «Рекорды»: топ-10 и своя строка (список сам прокручивается к ней), без имён других игроков — место, весёлая клавиша и счёт. Гостю — «Войти» с объяснением выгоды; перед входом прогресс гостя уходит в облако, после — прогресс аккаунта читается из облака и важнее локального кэша. После окна выбора аккаунта прогресс перечитывается и игра выходит в меню.
- M3, отзыв и ярлык: оценку просим после первого Энтера или нового рекорда с третьего доигранного забега, не больше одного раза. После пятого забега в меню кнопка «На рабочий стол» — если площадка разрешает ярлык; после согласия кнопка исчезает навсегда.
- M3, флаги remote config: `goldenChance`, `interstitialCooldownSec`, `spawnWeights`, `secondChanceEnabled` — строки из SDK проверяются по одному, битый флаг заменяется значением из `config/balance.ts`.
- M3, бот и soak: `?bot=1` — бот сам играет в обычном темпе (для промо-видео), `?bot=fast` — быстро и небрежно; иногда смотрит рекламу за награду. `npm run soak` — бот играет 10 минут: в облачном контейнере без видеокарты за 10 минут — 3 доигранных забега (каждый раз через окно «Второго шанса» и экран результата), ни одной ошибки в консоли, память после сборки мусора 8–10 МБ без роста (после разогрева 9,7 МБ, в конце 8,5 МБ).

Золотая клавиша (шанс 2 %, +1 % за уровень апгрейда): золотой корпус, рамка и искорки, результат слияния с ней тоже золотой. «Встряска» и «Удаление» с числом зарядов (появляются после покупки). Новая форма сразу записывается в альбом: из слияния — крупный показ «НОВАЯ ФОРМА!» (физика стоит 1 с), Пробел — «ЛЕГЕНДАРНАЯ ФОРМА!» на 3 с (пропуск тапом), упавшая сверху — наклейка «Новая!», золотая — плашка. Достижения — плашкой с наградой.
- M2, обучение: рука-перчатка показывает «веди → отпусти» с полупрозрачной клавишей и целится в такую же клавишу в банке; первые клавиши — Точка, Точка, Запятулька; после первого слияния рука больше не появляется. Через 30 с игры рука показывает «тап-тап» по клавише, пока игрок сам не тапнет.

Пасхалки: мелодия на буквах логотипа слева направо — достижение «Пианист»; «КЛАЦ» или «CLACK» на клавиатуре в меню — дождь из клавиш и достижение «Тайное слово»; без касаний 25 с персонажи засыпают (над ними летят «z»); когда в банке появляется Пробел, все клавиши радуются и подпрыгивают.

## Известные баги

- `npm run dev:ya` в облачном контейнере Claude не получает моки SDK: прокси Яндекса скачивает их с `yastatic.net`, а этот домен в контейнере закрыт (ответ 403). На обычном компьютере с интернетом всё работает. Проверено, что Vite и прокси запускаются, прокси отдаёт игру на https://localhost:8080 и оба процесса останавливаются по Ctrl+C.
- Прокси Яндекса падает, если в системе нет программы для открытия браузера (`xdg-open` на Linux без рабочего стола). На Windows и macOS этого нет.
- Автотесты в облачном контейнере идут медленно: без видеокарты WebGL рисует процессор (на холсте 1536×2048 — несколько кадров в секунду), а первые 120 кадров после старта Phaser ограничивает шаг времени 1/60 с. Игровое время там отстаёт от реального, поэтому тесты ждут событий, а не фиксированное время. На телефоне с 60 кадрами в секунду этого не видно; если телефон рисует меньше 15 кадров в секунду, игра идёт медленнее, а не «прыгает».

## Принятые решения

- **Phaser 3.90.0 закреплён точно.** В npm «последняя» версия уже 4.x, а по ТЗ нужен Phaser 3.
- **TypeScript 6.0, а не 7.0.** Линтер typescript-eslint пока поддерживает TypeScript только до 6.0.
- **Сборка под iOS 12+ / Chrome 61+ / Firefox 60+.** По умолчанию Vite 8 собирает под iOS 16.4+, а требования Яндекса (п. 1.20) перечисляют старые устройства. iOS 9–11 не поддерживаем: без отдельной «старой» сборки там не запустится ни Vite-бандл, ни Phaser.
- **Встроенный звук Phaser выключен** (`audio.noAudio`), чтобы браузер не создавал AudioContext до первого жеста игрока. Звук будет синтезироваться через WebAudio (M1).
- **Облачные сохранения укладываются в лимит Яндекса.** `player.setData` — не больше 100 запросов за 5 минут, превышение — причина отказа модерации (п. 1.14). Поэтому изменения за 1 с склеиваются в одну запись (как требует ТЗ), а записей не больше 90 за 5 минут: запас оставлен под `getData`. Срочная запись (пауза, скрытие вкладки) уходит сразу, если лимит позволяет. Ошибки записи повторяются с паузой, данные не теряются: каждая запись отправляет самое свежее сохранение.
- **Снимок текущего забега (M1) будет храниться только в локальном кэше.** Снимок каждые 5 с в облако съел бы весь лимит запросов. ТЗ не требует хранить снимок именно в облаке.
- **Какое сохранение брать при старте:** из облака и локального кэша берётся то, у которого больше `rev` (счётчик изменений); при равенстве — облачное.
- **Сохранение от более новой версии игры не затирается.** Если в облаке или кэше данные новее, чем умеет читать эта сборка (например, старая копия игры в кэше браузера), игра запускается, но ничего не записывает.
- **Битые поля заменяются по одному**, а не всё сохранение целиком: если сломана одна настройка, остальной прогресс остаётся.
- **Без `structuredClone` и других новых API:** их нет на iOS 12–15, а полифилов в игре нет. Это проверяют `lib: ES2019` в `tsconfig.app.json` и правило линтера.
- **Пауза игрока не выключает звук**, выключают только системные причины: так перечислено в ТЗ (вкладка, фокус, пауза SDK, реклама). После системной паузы забег продолжается сам, если игрок не ставил паузу; экран паузы при этом не показывается.
- **`GameplayAPI.stop()` вызывается и при потере фокуса/уходе с вкладки**, а не только в случаях из CLAUDE.md: модерация проверяет эти сценарии (п. 1.19.3).
- **Шрифт — вариативный Nunito**, только наборы «латиница» и «кириллица»: 60 КБ на все толщины. В шрифте нет символа «⌫» (надпись клавиши 10-го тира), его нарисуем кодом в M1. Стрелка «↑» в шрифте есть.
- **Лицензия шрифта лежит в сборке** (`licenses/nunito-OFL.txt`): OFL требует распространять её вместе со шрифтом. В игре она не показывается.
- **Интерфейс Platform в M0 содержит только нужное каркасу** (подключение, язык, тип устройства, ready, разметка геймплея, пауза от площадки, сохранения). Реклама, покупки, лидерборд и остальное появятся в M3 вместе с реализацией, чтобы не было пустых заглушек.
- **Прокси Яндекса для `npm run dev:ya` не добавлен в зависимости.** Он тянет старый Express с известными уязвимостями (8 штук по `npm audit`), а нужен только на компьютере разработчика. Скрипт `scripts/dev-ya.ts` запускает его через `npm exec` с закреплённой версией 0.0.2, как `npx` в CLAUDE.md. В самой игре уязвимостей нет.
- **Облачную запись отправляем с `flush: true`.** Тогда один вызов `setData` — ровно один запрос, и планировщик точно держит лимит.
- **Типы SDK — официальный пакет `@types/ysdk`**, его рекомендует документация Яндекса (`docs/yandex/sdk/typescript.md`). Только для разработки, в игру не попадает.
- **Раскладка экрана** (`src/core/layout.ts`): колонка во всю высоту; на широком экране её форма 9:16, но не уже 360 CSS-пикселей (телефон в альбомной ориентации получает почти квадратную колонку, а не узкую полоску); на десктопе стороны колонки не больше 2:1 (п. 1.6.2.2). Минимальная кнопка — 110 логических пикселей, это не меньше 48 CSS-пикселей на всех целевых экранах, включая 320×568; это проверяют тесты.
- **На низком экране меню перестраивается** в три колонки кнопок вместо двух, длинные надписи уменьшаются, чтобы поместиться в кнопку.
- **Фон рисуется отдельной постоянной сценой** под всеми экранами: градиент через canvas-текстуру (работает и в WebGL, и в запасном Canvas-рендере) и светлая подложка под колонкой.
- **Потеря фокуса снимается и касанием игры**: на мобильных событие `focus` приходит не всегда, а зависшая пауза остановила бы забег.
- **Хуки для автотестов** (`window.__e2e`, метка `<body data-scene>`) включаются только параметром `?e2e` в адресе. Метка экрана безвредна и есть всегда.
- **Уважаем «уменьшить движение»** (`prefers-reduced-motion`): пульсация кнопки «ИГРАТЬ» отключается. Заодно скриншоты автотестов получаются одинаковыми при каждом запуске.
- **Автотесты проверяют прод-сборку** (`vite build` + `vite preview`), а не dev-сервер: так проверяется ровно то, что уйдёт в архив.
- **Скриншоты делаются с «уменьшить движение»**, поэтому при повторном запуске на той же машине они не меняются. На другом компьютере шрифты и сглаживание могут отрисоваться чуть иначе — это нормально.
- **В проверке консоли отфильтрованы два сообщения самого Chromium** о программном WebGL (в облачном контейнере нет видеокарты). Проверено, что игра не вызывает `readPixels`. Остальные ошибки и предупреждения валят тест.
- **ZIP-упаковщик свой** (`scripts/lib/zip.ts`, ~100 строк на встроенном `node:zlib`), без новых зависимостей. Даты файлов фиксированы, порядок — по алфавиту, имена с пробелами и кириллицей он не пропустит.
- **`npm run moderation` проверяет и `dist/`, и `src/`.** Три правила из CLAUDE.md по сборке не проверить: в бандле весь код склеен, в нём есть и `localStorage` самого Phaser. Поэтому «хранилище только в `platform/`», ключи ru/en и покупки проверяются по исходникам.
- **Белый список адресов в сборке — 3 строки из Phaser:** пространства имён XML (`http://www.w3.org/2000/svg`, `http://www.w3.org/1999/xhtml`) и адрес сайта в тексте его баннера (`https://phaser.io`). Это не сетевые запросы. Файлы лицензий в папке `licenses/` не проверяются: в тексте OFL есть ссылки.
- **Цены в `purchases-catalog.json` тестовые** (99, 49 и 29 ян): каталог нужен только моку SDK. Настоящие цены задаются в Консоли разработчика.
- **Правила архитектуры проверяет линтер:** `localStorage`, `sessionStorage` и `YaGames` разрешены только в `src/platform/`; `src/core/` не импортирует Phaser и не трогает `window`/`document`; сцены не импортируют конкретные платформы.
- **Node.js 22.18+ (или 24+).** Служебные скрипты (`scripts/*.ts`) написаны на TypeScript, а запускать их без дополнительных флагов Node умеет только с версии 22.18. Раньше в `package.json` было указано 22.13 — на 22.13–22.17 `npm run moderation`, `zip` и `dev:ya` не запустились бы.
- **Переводы строк всегда LF** (`.gitattributes`). Git для Windows по умолчанию меняет их на CRLF, и тогда проверка форматирования в `npm run check` падала бы на каждом файле.
- **Пустая иконка вкладки** (`<link rel="icon" href="data:,">` в `index.html`). Без неё обычный браузер запрашивает `/favicon.ico` и пишет в консоль ошибку 404. В Яндекс Играх игра открывается во фрейме, иконка там не видна.
- **Автотесты можно запустить в установленном браузере:** `PW_CHANNEL=msedge` или `PW_CHANNEL=chrome`, если браузер Playwright не скачивается. Проверено на полной версии Chromium в облаке (она и показала ошибку с favicon); в Edge под Windows ещё не запускалось. Скриншоты с другим браузером и шрифтами могут чуть отличаться — они только сохраняются, а не сравниваются.

### Решения M1

- **Физика — в отдельном классе `Run` без Phaser.** Matter.js берётся из сборки Phaser (`Phaser.Physics.Matter.Matter`), отдельной библиотеки нет. Так весь забег проверяется тестами и ботом в Node на той же физике, что в игре. Нужная часть API Matter.js описана своими типами: описание в Phaser отстаёт от самой библиотеки 0.20.
- **Фиксированный шаг физики 60 Гц** с плавной отрисовкой между шагами (для экранов 90–120 Гц). Не больше 4 шагов за кадр: на очень медленном устройстве игра замедляется, а не «прыгает».
- **Невидимые стенки банки уходят высоко вверх и толстые:** подброшенная клавиша не вылетит наружу и не пролетит сквозь дно даже на большой скорости.
- **Слияния считаются по событиям `collisionStart` и `collisionActive`:** клавиши, которые уже лежат вплотную, тоже сливаются. Если клавиша касается двух одинаковых соседей, она сливается с той, что появилась раньше; за один шаг каждая клавиша сливается не больше раза. Новая клавиша появляется ровно (без наклона) посередине, не заходя в стенки, с небольшим толчком вверх.
- **Угловое демпфирование сделано вручную** (12 % угловой скорости за шаг) плюс момент инерции ×3: в Matter.js нет отдельного углового демпфирования, а клавиши должны быстро оседать. Клавиши всё равно могут перевернуться — это физика, а не ошибка.
- **Очки растут вдвое с каждым тиром** (10, 20, 40 … 5120 за Пробел, мега-клац — 20 000). Так каждый уровень слияний даёт примерно одинаковый вклад, а крупные цифры приятны детям.
- **Смещение спавна с 3-й минуты плавное:** с 180-й по 300-ю секунду веса переходят от [30, 28, 22, 14, 6] к [22, 25, 24, 18, 11] — к тирам 3–5, но не выше (диздок, раздел 7).
- **Тап по лежащей клавише — сквиш, а не сброс.** Для пальца есть допуск 14 единиц вокруг клавиши. Тап сбоку слегка толкает клавишу в сторону — маленький инструмент для скилла. Большие клавиши подпрыгивают ниже маленьких. Мышью прицел ведётся и без нажатия.
- **Пауза между сбросами 0,45 с,** нажатия в это время не копятся: иначе ребёнок, быстро тапающий по экрану, получит неожиданные двойные сбросы.
- **«Осевшая» клавиша — та, что после сброса чего-то коснулась** (или падает дольше 1,5 с). Только такие проверяются линией опасности, время над линией считается для каждой клавиши отдельно.
- **Мега-клац сделан уже в M1** (два Пробела исчезают с фейерверком и дают 20 000 очков): без него два Пробела просто лежали бы рядом. Монеты за него — в M2 вместе с остальными монетами.
- **Выход в меню посреди забега** удаляет снимок, но хороший счёт становится рекордом. Забегом (для счётчика забегов) считается только доигранный до переполнения.
- **На лежащем телефоне HUD уходит в стороны от банки,** если так банка получается заметно крупнее: сверху места мало, а по бокам много.
- **Лицо клавиши не налезает на надпись в углу:** если места мало, лицо уменьшается и опускается под надпись. У Капса нет бровей — так его «кричащее» лицо помещается крупным.
- **Esc и P — пауза и продолжение;** в CLAUDE.md их нет, но это привычно на десктопе и не системные сочетания.
- **Звук включается по событиям `pointerup`, `touchend` и `keydown`** (кроме Esc): браузеры считают жестом именно их, по `pointerdown` пальцем звук не запустится.
- **Для автотестов — `?e2e&seed=…`:** одинаковый seed даёт одинаковые клавиши, скриншоты при повторном прогоне совпадают байт в байт. При «уменьшить движение» клавиши не дышат и не моргают, счёт на экране результата появляется сразу.

### Решения M2

- **Монеты за забег попадают в кошелёк в конце забега** (и при выходе в меню — без бонуса за очки), а награды за достижения — сразу. В забеге счётчик показывает только монеты этого забега.
- **Форма открывается, когда впервые появляется в банке.** Показ «НОВАЯ ФОРМА!» с остановкой физики — только для форм из слияния: формы 1–5 чаще всего впервые падают сверху, и остановка на каждой мешала бы первому забегу; им достаётся наклейка «Новая!». Золотая форма открывает и обычную.
- **Золотая клавиша узнаваема:** золотые корпус и рамка, а верхняя грань своего цвета, поэтому ребёнок видит, что золотая Буквуля сольётся с обычной Буквулей. Текстуры золотых клавиш рисуются лениво — при первой встрече.
- **«Встряска» и «Удаление» видны только после покупки.** «Удаление»: нажать кнопку, потом клавишу; тап мимо или повторное нажатие кнопки отменяют. Пока режим включён, сброса нет. Когда закончились заряды, кнопка бледная; предложение «+1 за рекламу» появится с рекламой в M3.
- **Кнопки инструментов — под банкой** (у большого пальца), на лежащем телефоне — справа от банки; если под банкой мало места, банка немного уменьшается.
- **Обучение считается пройденным после первого слияния,** подсказка про сквиш — после первого своего тапа по клавише. Хранится в сохранении, поэтому не повторяется на другом устройстве.
- **Альбом — одна листаемая страница** (формы, золотые формы, достижения): так проще, чем вкладки. Кнопки в листаемых списках нажимаются, только пока видны целиком. Секретные достижения до получения показаны как «Секретное достижение».
- **Персонажи меню и дождь из клавиш — только из открытых форм** (и первые три клавиши, которые новый игрок видит сразу): неоткрытые формы остаются тайной для альбома.
- **Логотип не меняет название игры:** имя «Сквиши Клавиши» на клавишах, подпись «Мерж до Пробела» строкой ниже; обе части берутся из той же строки `game.title`.
- **Тайное слово определяется по `event.code`:** «КЛАЦ» на русской раскладке — это физические клавиши R, K, F, W, поэтому пасхалка работает при любой раскладке. Отдельные буквы — не системные сочетания.
- **Цвета фона — в данных мира** (`skyTop`, `skyBottom`, `pattern`, `patternLine` в `themes/`): новый мир получит свой фон без правок кода. Плитка узора 512×256 — степень двойки, WebGL повторяет её без растяжения.
- **«Неделя подряд»** появится в M4 вместе с ежедневными заданиями; остальные достижения из диздока уже есть.
- **Игра одним файлом (`npm run offline`)** — по просьбе владельца. Код, стили и шрифты встроены в страницу, а тег `/sdk.js` убран: с диска его не загрузить, и игра сама переходит на локальную площадку. Проверено в Chromium с диска: меню со шрифтом, забег, сохранение после перезагрузки, ни одного сетевого запроса и ни одной ошибки в консоли. Для модерации этот файл не годится — там нужен архив с тегом SDK.
- **Автотесты не про мету играют «опытным игроком»** (всё открыто, обучение пройдено), иначе показы новых форм останавливали бы физику посреди проверки. Мету проверяет отдельный набор `e2e/meta.spec.ts`. Хук `patchSave` подменяет части сохранения через ту же проверку, что и облачные данные.

### Решения M3

- **Награда за рекламу выдаётся только в колбэке `onRewarded`.** «Второй шанс», заряд инструмента и монеты начисляются прямо в нём; экран обновляется, когда реклама закрыта.
- **Полноэкранная реклама ждёт 90 с и после рекламы за награду:** ребёнок не получит две рекламы подряд. Платформа и сама не покажет рекламу слишком часто — игра это спокойно переживает.
- **«Второй шанс» без таймера обратного отсчёта:** диздок запрещает давление. Окно ждёт решения сколько угодно, «Нет, спасибо» сразу ведёт к результату.
- **«+1 за рекламу» — через окно-предложение,** а не реклама прямо по кнопке инструмента: случайный тап ребёнка посреди забега не должен включать рекламу. Пока окно открыто, забег на паузе. Клавиатурой рекламу не включить — только осознанным нажатием кнопки.
- **Если реклама не открылась за 8 с, игра продолжает** (как «реклама недоступна»): зависшая пауза хуже пропущенной рекламы. Если реклама всё же откроется позже, платформа сама пришлёт `game_api_pause`.
- **Стики-баннер — через API SDK,** хотя диздок говорил «в коде ничего не нужно»: только так покупка «Без рекламы» убирает и баннер (п. 1.13.5). В консоли нужно включить «Использовать API для показа sticky-баннера» — пункт есть в ручном чек-листе `npm run moderation`.
- **Иконка портальной валюты — единственный сетевой запрос игры:** её адрес даёт SDK, и показывать её обязательно (п. 1.13.2). Если иконка не загрузилась, остаётся код валюты из каталога («YAN») — цена всё равно видна. Это стоит проверить в черновике с моками валюты (TST и ¥).
- **Описания товаров — из переводов игры,** а цена и валюта — из каталога SDK: так тексты грамотные на обоих языках. Тексты в `purchases-catalog.json` и в консоли должны говорить то же самое.
- **«Набор украшений» продаётся с M4,** когда появились сами банки и фоны: без них покупка не соответствовала бы описанию (п. 1.13.5). Описание перечисляет все украшения набора — это проверяет юнит-тест.
- **В таблице рекордов нет имён других игроков:** это пользовательский текст, а игра детская (CLAUDE.md). Вместо имени — место, медаль для 1–3 мест и клавиша-персонаж; своя строка подписана «Ты».
- **После входа облако аккаунта важнее локального кэша,** даже если у кэша гостя счётчик изменений больше: этот прогресс выбрал игрок в окне платформы или перенесла сама платформа. Выбранный прогресс сразу записывается и в облако, и в кэш.
- **Оценку просим после нового рекорда начиная с третьего забега,** а не только в третьем: без входа площадка не разрешает отзыв (`NO_AUTH`), и гость иначе никогда бы его не увидел. Окно показывается не больше одного раза; «уже оценили» тоже считается.
- **Без Яндекса (`npm run dev`, игра одним файлом) покупок, входа и рекордов нет** — экраны честно говорят «пока недоступны». Реклама там — заглушка на секунду с наградой. Проверять покупки и вход — через `npm run dev:ya` или черновик в консоли.
- **`dailyRewardCoins` появится в M4** вместе с ежедневным подарком: флаг без того, что его читает, был бы мёртвым кодом.
- **Снимок забега v3** хранит, какие бонусы за рекламу уже взяты; снимки v2 тоже читаются — забег, прерванный обновлением игры, не пропадёт.
- **Бот играет «руками» игрока:** прицел и сброс как с клавиатуры, кнопки — как пальцем. Для soak-теста он играет опытным игроком (всё открыто), иначе показы новых форм замедляли бы забеги.

### Решения M4

- **Сохранение v5** (миграция с v4): выбранный и купленные миры, ежедневное, украшения. Флаги «подсказка про Карамельку / Метеорчик уже была» добавлены без новой версии: в старых сохранениях их просто нет, и игра считает, что подсказки ещё не было.
- **Мир открыт, если он первый, куплен или в альбоме есть Пробел прошлого мира.** Открытие считается по альбому, поэтому кто уже вырастил Пробел до M4, получит второй мир сразу. Цены — 3000 и 8000 (диздок), для будущих миров — +4000 за каждый следующий.
- **День «Клавиши дня» — по серверному времени и часовому поясу игрока:** новый день наступает в местную полночь. Если часы на устройстве перевели назад больше чем на два дня, день начинается заново, а не «застревает».
- **«Клавиша дня» по силам:** форма из открытого мира на 0–2 ступени ниже лучшей формы игрока в этом мире (от Стрелочки до Бэкспейса), одинаковая у всех в этот день.
- **«Карамелька» прилипает только ниже линии опасности:** прилипшая наверху сразу заканчивала бы забег — клавиши ложились бы на неё. Пока висит, линия опасности её не считает.
- **Таймер «клавиша упала» в лёгком мире длиннее** (делится на √гравитации): клавиши там падают медленнее, и прежний таймер срабатывал в воздухе.
- **Стенки банки — гладкое стекло (трение 0), «упала» — это дно или другая клавиша.** Matter.js сам ставит неподвижным телам трение 1, поэтому трение стенок задаётся после создания. Подробно — «Баланс M4».
- **Карусель миров листают только стрелки ←/→:** A и D заняты тайным словом «CLACK» в меню.
- **Пробный забег за рекламу:** мир остаётся закрытым; на экране результата вместо «Ещё раз» — «▶ Реклама: ещё забег», в меню — обычный путь.
- **Банка-украшение видна со следующего забега,** а фон — сразу: менять банку посреди забега незачем, а фон виден в меню.
- **Превью фона в магазине рисуется тем же кодом, что и сам фон,** только мельче: что видно в магазине, то и будет на экране.
- **Вкладка «Медали», а не «Достижения»:** длинное слово не помещалось на вкладку; внутри вкладки заголовок — «Достижения».

## Как запускать (для владельца)

Нужен Node.js 22.18 или новее: https://nodejs.org, кнопка «LTS». Проверить версию: команда `node -v`.

Первый раз (Windows):

1. Скачать проект: https://github.com/pgpgmgg328-cmyk/game/archive/refs/heads/claude/peaceful-turing-i6fayt.zip и распаковать («Извлечь всё»). Проект — это папка, в которой лежит файл `package.json`. Её удобно перенести в короткий путь, например `C:\games\squishy-keys`.
2. Открыть эту папку в Проводнике, в адресной строке набрать `cmd` и нажать Enter — откроется командная строка сразу в папке проекта. Из другой папки (например, `C:\Windows\System32`) команды не сработают: там нет `package.json`.
3. `npm install` — скачивает библиотеки в папку `node_modules`, нужно один раз.

Каждый раз (в командной строке в папке проекта):

- `npm run dev` — игра в браузере на http://localhost:5173 (без SDK, английский язык — http://localhost:5173/?lang=en). Остановить — Ctrl+C.
- `npm run dev:ya` — игра с моками SDK Яндекса на https://localhost:8080 (браузер предупредит о самоподписанном сертификате — это нормально для локального запуска).
- `npm run check` — проверки кода и юнит-тесты.
- `npm run offline` — вся игра одним файлом `release/squishy-keys-vX.Y.Z-offline.html`: открывается двойным щелчком, без сервера и интернета, прогресс хранится в этом браузере. Чтобы поиграть или показать; в Яндекс Игры загружается архив из `npm run zip`.
- `npm run soak` — бот играет 10 минут подряд и проверяет, что нет ошибок и память не растёт (`set SOAK_MINUTES=3` — короче).
- `npm run e2e` — автотесты в браузере и скриншоты. Для ручной проверки они не нужны. Им нужен отдельный браузер: `npx playwright install chromium` (запускать в папке проекта). Если он не скачивается, можно взять Edge, который есть в Windows: сначала `set PW_CHANNEL=msedge`, потом `npm run e2e`.

1. Данные мира 1 (`src/themes/`) и числа баланса (`src/config/balance.ts`). Проверка: тесты данных (11 форм, размеры растут, у всех имён есть ru и en).
2. Логика забега без Phaser (`src/core/run/`): случайные числа с seed, выбор клавиши (веса и сдвиг с 3-й минуты), слияния с защитой от двойного слияния, мега-клац, линия опасности (2 с), счёт, комбо, снимок забега. Проверка: юнит-тесты.
3. Физика банки на Matter.js (`src/game/run/`, без Phaser): скруглённые тела, фиксированный шаг, угловое демпфирование, слияния по столкновениям, импульс вверх, тап-сквиш. Проверка: тесты в Node с настоящим Matter.js.
4. Процедурная графика: клавиши, лица, моргание, банка, частицы. Проверка: скриншоты.
5. Экран забега: счёт, рекорд, следующая клавиша, управление пальцем, мышью и клавиатурой, анимации, пауза, поворот экрана. Проверка: e2e и скриншоты на 6 разрешениях.
6. Звук: синтез WebAudio, тон по тиру, комбо, лимитер громкости, тихая музыка, выключение на паузе и при скрытии. Проверка: тесты менеджера звука, ручная проверка.
7. Конец забега и экран результата, рекорд в сохранении (схема v2 с миграцией). Проверка: юнит-тесты миграции, e2e.
8. Снимок забега каждые 5 с, при паузе и скрытии; «Продолжить забег?» после перезагрузки. Проверка: e2e с перезагрузкой.
9. Баланс: бот без браузера играет сотни забегов, подбираем высоту банки и веса, чтобы забег длился 3–8 минут. Итог — в этом файле.
