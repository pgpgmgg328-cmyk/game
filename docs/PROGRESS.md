## Известные баги

- `npm run dev:ya` в облачном контейнере Claude не получает моки SDK: прокси Яндекса скачивает их с `yastatic.net`, а этот домен в контейнере закрыт (ответ 403). На обычном компьютере с интернетом всё работает. Проверено, что Vite и прокси запускаются, прокси отдаёт игру на https://localhost:8080 и оба процесса останавливаются по Ctrl+C.
- Прокси Яндекса падает, если в системе нет программы для открытия браузера (`xdg-open` на Linux без рабочего стола). На Windows и macOS этого нет.

## Принятые решения

- **Phaser 3.90.0 закреплён точно.** В npm «последняя» версия уже 4.x, а по ТЗ нужен Phaser 3.
- **TypeScript 6.0, а не 7.0.** Линтер typescript-eslint пока поддерживает TypeScript только до 6.0.
- **Сборка под iOS 12+ / Chrome 61+ / Firefox 60+.** По умолчанию Vite 8 собирает под iOS 16.4+, а требования Яндекса (п. 1.20) перечисляют старые устройства. iOS 9–11 не поддерживаем: без отдельной «старой» сборки там не запустится ни Vite-бандл, ни Phaser.
- **Встроенный звук Phaser выключен** (`audio.noAudio`), чтобы браузер не создавал AudioContext до первого жеста игрока. Звук будет синтезироваться через WebAudio (M1).
- **Облачные сохранения укладываются в лимит Яндекса.** `player.setData` — не больше 100 запросов за 5 минут, превышение — причина отказа модерации (п. 1.14). Поэтому изменения за 1 с склеиваются в одну запись (как требует ТЗ), а записей не больше 90 за 5 минут: запас оставлен под `getData`. Срочная запись (пауза, скрытие вкладки) уходит сразу, если лимит позволяет. Ошибки записи повторяются с паузой, данные не теряются: каждая запись отправляет самое свежее сохранение.
- **Снимок текущего забега (M1) будет храниться только в локальном кэше.** Снимок каждые 5 с в облако съел бы весь лимит запросов. ТЗ не требует хранить снимок именно в облаке.
- **Какое сохранение брать при старте:** из облака и локального кэша берётся то, у которого больше `rev` (счётчик изменений); при равенстве — облачное.
- **Сохранение от более новой версии игры не затирается.** Если в облаке или кэше данные новее, чем умеет читать эта сборка (например, старая копия игры в кэше браузера), игра запускается, но ничего не записывает.
- **Битые поля заменяются по одному**, а не всё сохранение целиком: если сломана одна настройка, остальной прогресс остаётся.
- **Без `structuredClone` и других новых API:** их нет на iOS 12–15, а полифилов в игре нет. Это проверяют `lib: ES2019` в `tsconfig.app.json` и правило линтера.
- **Пауза игрока не выключает звук**, выключают только системные причины: так перечислено в ТЗ (вкладка, фокус, пауза SDK, реклама). После системной паузы забег продолжается сам, если игрок не ставил паузу; экран паузы при этом не показывается.
- **`GameplayAPI.stop()` вызывается и при потере фокуса/уходе с вкладки**, а не только в случаях из CLAUDE.md: модерация проверяет эти сценарии (п. 1.19.3).
- **Шрифт — вариативный Nunito**, только наборы «латиница» и «кириллица»: 60 КБ на все толщины. В шрифте нет символа «⌫» (надпись клавиши 10-го тира), его нарисуем кодом в M1. Стрелка «↑» в шрифте есть.
- **Лицензия шрифта лежит в сборке** (`licenses/nunito-OFL.txt`): OFL требует распространять её вместе со шрифтом. В игре она не показывается.
- **Интерфейс Platform в M0 содержит только нужное каркасу** (подключение, язык, тип устройства, ready, разметка геймплея, пауза от площадки, сохранения). Реклама, покупки, лидерборд и остальное появятся в M3 вместе с реализацией, чтобы не было пустых заглушек.
- **Прокси Яндекса для `npm run dev:ya` не добавлен в зависимости.** Он тянет старый Express с известными уязвимостями (8 штук по `npm audit`), а нужен только на компьютере разработчика. Скрипт `scripts/dev-ya.ts` запускает его через `npm exec` с закреплённой версией 0.0.2, как `npx` в CLAUDE.md. В самой игре уязвимостей нет.
- **Облачную запись отправляем с `flush: true`.** Тогда один вызов `setData` — ровно один запрос, и планировщик точно держит лимит.
- **Типы SDK — официальный пакет `@types/ysdk`**, его рекомендует документация Яндекса (`docs/yandex/sdk/typescript.md`). Только для разработки, в игру не попадает.
- **Правила архитектуры проверяет линтер:** `localStorage`, `sessionStorage` и `YaGames` разрешены только в `src/platform/`; `src/core/` не импортирует Phaser и не трогает `window`/`document`; сцены не импортируют конкретные платформы.
